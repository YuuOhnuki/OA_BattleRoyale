## マップとロビーを用意する
1. マップを作る空き地の上端にしたい場所へ移動します（例：X0/Y80/Z0）。管理メニューのマップ生成を選びます。この操作は実行者を観戦モードにします。
2. 生成は基準X/Z−152〜+152、Y−20〜Y（中央広場のドーム骨組みのみY+29まで）。中央地面は基準Y−11、立つ位置はY−10です。BR専用ディメンションでは基準Y=80、中央地面Y=69です。基準Yは0〜250。準備チェックで生成完了と登録成功（チェスト59／鉱石108）を確認してください。
3. マップと重ならない別の空き地へ移動し、ロビー作成を選びます。ロビーは81×81、基準Y−3〜Y+44を上書きします。作成Yは−61〜275。
4. `/trigger oa.return` で観戦から参加へ戻り、ロビー中央へ移動します。参加登録だけなら `/trigger br.join` も使えます。
5. 準備チェックでBR中心・基本設定・ロビー・マップ処理状態・登録成功件数・参加人数・チーム未選択を確認します。リソースパックの適用は各自の画面で確認してください。

地形や照明の更新を反映するにはマップ全面再生成、ロビーの配置を反映するにはロビー再建が必要です。どちらも既存の同範囲を上書きします。準備チェックの登録件数は自動生成の結果であり、後から手で壊した全チェスト等の存在を完全監査するものではありません。開始コマンドには保存品や人数の追加検査も残しています。
マップは北に山岳・雪、東に密度のある森と遺跡、西に市街地、南に浜・港・船。道路の埋め込み照明、岩・壁の遮蔽物、ジャンプパッド27か所があります。石の感圧板＋レンガが目印で、試合の生存参加者が踏むと添付版の物理キャリア方式で発射します。ジャンプパッドを反映するにはマップを全面再生成します。生成範囲の既存建築は上書きするためバックアップしてください。ロビーのBR俯瞰図は8×8ブロック、背面は正方形。以前の表示中心から3ブロック下へ移動し、OAの文字を上向きに読める元画像の向きに統一しています。OAが正向きに読めるよう左右表示を補正した固定画像で、プレイヤー位置や試合中の変化は反映しません。

## プレイヤーの遊び方
`/trigger oa.menu` で案内、`/trigger br.lobby` でロビー移動。羊毛に乗るとチーム選択、灰色は観戦。観戦時のチャットの「参加へ戻る」をクリックするか `/trigger oa.return` で戻れます。試合中は復帰できません。
ホストが開始パッドに5秒立つと最後の3秒をカウントし開始。管理メニューから直接開始することもできます。開始前の所持品・経験値・ゲームモードを保存し、採掘用ツルハシのみを配布してランダム配置します。
最初の1分はPvP・通常環境ダメージから保護。終了はタイトルと効果音で通知。初期安置は300×300で、2〜3分230、4〜5分160、6〜7分90、9〜10分20、決着しなければ10〜11分2へ縮小します。各収縮の3・2・1秒前にベルを1回ずつ鳴らします。待機の最後10秒は収縮開始タイマー、収縮中は完了タイマーです。最終の連続収縮では既存の完了表示を維持します。
6分でチェストを1回上書き補充。石炭鉱石は食料、レッドストーン鉱石は医療品。登録鉱石は60秒で再生成し、実物の石炭・レッドストーンは出ません。各採掘は別途2%でゆーを追加抽選します。
固有装備は合計1個まで。スキルは右クリック、頭装備は右クリックで装着。主手に持つ固有装備の攻撃速度は1.8回/秒。頭へ装着しているときに別の通常武器の攻撃速度を変える効果ではありません。ゆー・通常バット・ノックバック棒にはこの指定を適用しません。
武器の説明とCTはアイテム説明欄を確認。アクションバーは固有装備名を優先します。ロケーターバーは完全非表示です。
昼夜は昼スタートで、昼→夜→昼の1周期5分（昼夜が約2分30秒ずつ）の4倍速です。試合中はBR専用クロックで時刻を制御します。終了後は開始前の時刻に戻ります。
試合終了後は所持品・経験値・ゲームモードを復元してロビー中央へ移動。試合外ボーダーは最大幅です。再接続時はロビーへ戻り、試合中の離脱は失格扱いです。

## 管理ブックでGM変更・復活
管理ブックの「GM・復活」から自分、または参加者一覧から対象を選びます。4種類のゲームモードと「復活」をクリックで操作できます。自分の操作一覧は `/trigger oa.admin set 38`、自分の復活は `/trigger oa.admin set 39`、全員の一覧は `/trigger oa.admin set 35`。登録済み管理者のみ操作できます。新しい本は `/trigger oa.admin set 16`。
ゲーム内の管理コマンドは `/function oa:manage {player:"MCID",action:"creative"}`。action は survival / adventure / creative / spectator / revive の5種類。復活の例は `/function oa:manage {player:"HitoriYuu",action:"revive"}`。バニラでは新しい独自スラッシュコマンド名を追加できないため、functionコマンド1行にまとめています。

死亡画面でHealthが0の間は操作を予約し、実際のリスポーン後に自動実行します（試合中は既存の即時リスポーン設定を使用）。バニラの管理コマンドだけでクライアントの死亡画面を直接操作することはできません。対象が退出した場合は予約を取り消します。終了演出中の「復活」はロビーへ戻すだけで、確定した勝敗は再開しません。


本体1.9.14では作業用ストレージをargs複合タグに統一し、管理者の試合復帰・ガチャ移動・雪玉／卵の補助押し出しの対象パスとマクロ引数を揃えています。ZIP交換後 `/reload` で反映します。リソパ交換・マップ再生成は不要です。




## 管理ブック・デバッグ
管理者は `/trigger oa.admin set 16` で新版の管理ブックを受け取れます。試合・準備・参加者・固有装備・通常アイテムを分類し、全9種類の固有装備を1ページにまとめました。一般プレイヤーの案内ブックも、操作→チーム→試合の流れ→アイテムの順に整理しています。

待機中に管理ブックの「デバッグ開始」を選ぶと、本人専用のデバッグブックを配布します。初期状態はCTなし、複数所持可、待機中も使用可、味方対象可、OA消耗品無消費、帽子・マスクの時間消耗なし、キリング取り外し可、モブ対象あり、ロビー回復なしです。ブックの制限ページで各項目を「あり／なし」に切替できます。変更後は本を開き直してください。「試合中・生存者限定」をありにすると待機中限定のデバッグでは該当する試合専用スキルが使えなくなります。

デバッグ設定は他人やワールド全体には適用しません。対象は半径48mの通常モブとデバッグ参加中の管理者で、展示物や一般のロビープレイヤーは対象外です。標的の牛・攻撃用ハスクを本から出せます。実ダメージを試す場合はサバイバルにしてください。ハスクは難易度ピースフルでは維持できません。

「デバッグ終了」、試合開始、死亡、退出後の再参加、リロードで通常設定へ戻ります。終了時に所持品を全消去しません。通常の1個制限へ戻った際の余剰固有装備は消さずに地面へ返します。生成した標的の削除は本の専用ボタンから行います。

消費なしはOAの包帯・応急キット・バフ医療品・ふろボール・ゆー、および雪玉・卵を対象とします。医療品とふろボールは使用後に同じアイテムが残る方式、雪玉・卵は使用回数分を次tickに返す方式です。通常の食料や装備の打撃耐久は対象外です。デバッグ中に変更したOAアイテムを地面へ捨てると通常設定へ戻します。

モブではプレイヤーと体格・重さ・移動AIが違うため、吹き飛び量等は同一にはなりません。空腹はプレイヤー専用です。待機中のガチャ復活結果は「脱落者なし」を表示し、通常試合の復活テストは実際の試合で行います。デバッグの集合・席替えは近くのテスト対象の位置を使い、中央登録を要求しません。搭乗中の発射制限、壁・未読込チャンクの安全確認、同時投射上限は解除しません。

新たなデバッグ用エンチャントを含むため、初回更新時はサーバーを再起動してください。リソパとマップの再生成は不要です。ファイル検査と静的な分岐検査のみ実施し、サーバー読み込み・プレイヤー・複数人テストは未実施です。

標的へのダメージは本当に発生します。一般モブの死亡・移動は元に戻せません。ロビー展示・無敵エンティティは自動選択から除外しています。モブの当たり箱に対する一部の追加効果判定は既存のプレイヤー向け近似を共用するため、大型・小型モブの端への命中では違いが出る可能性があります。固有装備を複数持てても常時強化は元の「装着・選択中の装備」の優先順位で処理します。全装備の常時効果が同時発動するモードではありません。

管理ブックの新版は全9固有装備を同じページに掲載しています。デバッグ時のモブには通常攻撃の魚ジャンプ・こまめ鈍足・ほちきす出血、音波・奇襲・拘束・ふろボールなどを適用します。雪玉・卵はバニラの飛行・衝突を維持し、消滅した直後の既存OA追加効果処理にもデバッグ対象を含めます。モブのノックバックにはMobのMotionを使う箇所があり、プレイヤーと移動距離は揃いません。
