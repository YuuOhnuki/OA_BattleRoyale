# OAバトルロワイヤル 1.9.14

Java Edition 26.3・バニラ用。最大10人、ソロまたは2〜3人の固定チーム。倒されたら観戦、最後の生存者／チームが優勝します。

## 導入
本体OA_BattleRoyale_v1.9.14.zipをワールド/datapacksへ、OA_BattleRoyale_Resources_v1.7.0.zipを各クライアントのresourcepacksへ入れます。本体には305×305のマップ生成とロビー生成も含まれます。旧本体・旧別配布マップ生成パック・旧リソースパックは重複させず交換してください。添付Jump Padの機能は本体へ統合済みです。同じjumppad名前空間の単独ジャンプパッドZIPは重複させず外してください。
サーバーで `/reload`、クライアントでリソースパックを有効化します。既存の所持品を導入だけで消去しません。

## 最初の設定と管理メニュー
OPがプレイヤーとして最初に1回だけ `/function oa:admin` を実行します。本人を管理者・開始ホストへ登録し、必要な基本設定を補完します。バニラのデータパックでは独自の /oa コマンドを登録できないため、初回登録時に「OA 管理ブック」が配布されます。右クリックで本を開き、青い項目をクリックして操作します。本のページは試合・生成・中心設定・再建と削除・通常アイテム・固有装備の入手・案内に分かれています。旧ブック所持者も /trigger oa.admin set 16 で新版を受け取れます。従来の `/trigger oa.admin` とチャットメニューも使用できます。本の再発行は `/trigger oa.admin set 16`。持ち物に既にある場合は追加配布しません。本を渡しても管理権限は移りません。ほかのプレイヤーが本や管理用triggerを実行しても、管理者タグがなければ拒否します。OP付与自体はサーバー管理者が行います。

| 操作 | コマンド |
|---|---|
| 管理ブック再発行 | /trigger oa.admin set 16 |
| チャット管理メニュー | /trigger oa.admin |
| 準備チェック | /trigger oa.admin set 2 |
| 現在地を基準にマップ新規生成 | /trigger oa.admin set 3 |
| 現在地にロビー作成 | /trigger oa.admin set 4 |

triggerは実行後に再び使えるようになります。短時間に連続入力した場合は次のtickまで待ってください。マップ生成・ロビー作成・再建は、説明された範囲の建築を上書きします。先にバックアップしてください。

## マップとロビーを用意する
1. マップを作る空き地の上端にしたい場所へ移動します（例：X0/Y80/Z0）。管理メニューのマップ生成を選びます。この操作は実行者を観戦モードにします。
2. 生成は基準X/Z−152〜+152、Y−20〜Y（中央広場のドーム骨組みのみY+29まで）。中央地面は基準Y−11、立つ位置はY−10です。BR専用ディメンションでは基準Y=80、中央地面Y=69です。基準Yは0〜250。準備チェックで生成完了と登録成功（チェスト59／鉱石108）を確認してください。
3. マップと重ならない別の空き地へ移動し、ロビー作成を選びます。ロビーは81×81、基準Y−3〜Y+44を上書きします。作成Yは−61〜275。
4. `/trigger oa.return` で観戦から参加へ戻り、ロビー中央へ移動します。参加登録だけなら `/trigger br.join` も使えます。
5. 準備チェックでBR中心・基本設定・ロビー・マップ処理状態・登録成功件数・参加人数・チーム未選択を確認します。リソースパックの適用は各自の画面で確認してください。

地形や照明の更新を反映するにはマップ全面再生成、ロビーの配置を反映するにはロビー再建が必要です。どちらも既存の同範囲を上書きします。準備チェックの登録件数は自動生成の結果であり、後から手で壊した全チェスト等の存在を完全監査するものではありません。開始コマンドには保存品や人数の追加検査も残しています。
マップは北に山岳・雪、東に密度のある森と遺跡、西に市街地、南に浜・港・船。道路の埋め込み照明、岩・壁の遮蔽物、ジャンプパッド27か所があります。石の感圧板＋レンガが目印で、試合の生存参加者が踏むと添付版の物理キャリア方式で発射します。ジャンプパッドを反映するにはマップを全面再生成します。生成範囲の既存建築は上書きするためバックアップしてください。ロビーのBR俯瞰図は8×8ブロック、背面は正方形。以前の表示中心から3ブロック下へ移動し、OAの文字を上向きに読める元画像の向きに統一しています。OAが正向きに読めるよう左右表示を補正した固定画像で、プレイヤー位置や試合中の変化は反映しません。

## プレイヤーの遊び方
`/trigger oa.menu` で案内、`/trigger br.lobby` でロビー移動。羊毛に乗るとチーム選択、灰色は観戦。観戦時のチャットの「参加へ戻る」をクリックするか `/trigger oa.return` で戻れます。試合中は復帰できません。
ホストが開始パッドに5秒立つと最後の3秒をカウントし開始。管理メニューから直接開始することもできます。開始前の所持品・経験値・ゲームモードを保存し、採掘用ツルハシのみを配布してランダム配置します。
最初の1分はPvP・通常環境ダメージから保護。終了はタイトルと効果音で通知。初期安置は300×300で、2〜3分230、4〜5分160、6〜7分90、9〜10分20、決着しなければ10〜11分2へ縮小します。各収縮の3・2・1秒前にベルを1回ずつ鳴らします。待機の最後10秒は収縮開始タイマー、収縮中は完了タイマーです。最終の連続収縮では既存の完了表示を維持します。
6分でチェストを1回上書き補充。石炭鉱石は食料、レッドストーン鉱石は医療品。登録鉱石は60秒で再生成し、実物の石炭・レッドストーンは出ません。各採掘は別途2%でゆーを追加抽選します。
固有装備は合計1個まで。スキルは右クリック、頭装備は右クリックで装着。主手に持つ固有装備の攻撃速度は1.8回/秒。頭へ装着しているときに別の通常武器の攻撃速度を変える効果ではありません。ゆー・通常バット・ノックバック棒にはこの指定を適用しません。
武器の説明とCTはアイテム説明欄を確認。アクションバーは固有装備名を優先します。ロケーターバーは完全非表示です。
昼夜は昼スタートで、昼→夜→昼の1周期5分（昼夜が約2分30秒ずつ）の4倍速です。試合中はBR専用クロックで時刻を制御します。終了後は開始前の時刻に戻ります。
