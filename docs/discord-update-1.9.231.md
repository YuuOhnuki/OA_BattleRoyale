# v1.9.231（天空都市・異界のリニューアル／ロビーのマップ選択）

**☁ 天空都市が「空に浮かぶ街」になりました**
・島の上に丘や段々の地形ができ、島の底は岩が垂れ下がる浮遊島らしい形に
・色とりどりの屋根の家、市場の屋台、2階建ての屋敷、**飛行船の発着場**（停まっている飛行船の甲板に乗れます）
・中央の天空城に時計塔と旗、中庭に屋台
・空には**熱気球と飛行船**が浮かんでいます（飾りなので乗れません）

**🌌 異界が「白い未来都市とコーラスの林」になりました**
・エンドストーンの段々の丘に、枝分かれした**コーラスの木**
・中央の異界神殿は白い神殿に。屋上にガラスのドーム、まわりに光る塔
・外周の島に「白い尖塔」「ガラスのドーム」が登場
・空には**光る結晶と円盤**が浮かんでいます（飾りなので乗れません）

**🗺 ロビーのマップ選択**
・受付のパネルの下が、**マップごとのボタン5つ**（地上・ネザー・洞窟・天空都市・異界）になりました。押すとそのマップに切り替わります（ホストのみ）
・ボタンの上に「選択中」「未生成」が出ます
・パネルに天空都市・異界の地図も出るようになりました（「？」の島は試合ごとに中身が変わります）
