# v1.9.199 TNT鬼とキリング・TDM調整

- TNT鬼はTNTを実際に頭へ装着。元の頭装備は地面へ落とし、鬼の間はキリング・ゆうあなどの強制装着を停止。
- キリングの無効化が通常攻撃・飛び道具でもパリィ音と粒子を出すよう、プラグインでダメージを止める方式へ。25%・1tick共有の抽選は維持。
- TDMキル時の再生をIVへ（速度上昇IIとともに5秒）。即時回復ドロップは10HP。
- TDMの選択武器は開始カウントダウン終了時に配布。

対応：データパック1.9.199＋プラグイン0.19.0＋リソースパック1.9.41。両方の配置後に再起動。会場・ロビー・練習場の更新は不要。
