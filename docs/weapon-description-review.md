# 固有武器・消耗品の説明（1.9.239）

ダメージは補充前を本文に、補充後を括弧内に記載。

体力は♥、満腹度は食料アイコンの個数で表示。ダメージは軽減前。

## ゆうあ：ピンク帯の麦わら帽子

敵を一撃で倒す代わりに、居場所が丸見えになる帽子。

- コマンドID：`yuua`
- モチーフ：yuuaHP
- 特徴：敵を一撃で倒す代わりに、居場所が丸見えになる帽子。
- 装備効果：拾うと頭へ強制装着。攻撃した敵・攻撃してきた敵へ即死攻撃。装着中は発光。
- CT：なし／装着の累計30秒で消滅
- 装着中：発光して位置が見える。キリングの無効化判定は受ける。
- 注意：1人1個の固有武器。TNT鬼の間は装着しない。

※固有武器は一人一個まで所持可能

**改善案（未実装・性能変更なし）：** 残り使用時間を帽子の説明と画面に表示すると判断しやすい。

## ネロノワール：ペスト医師の杖

印への帰還と本人デコイで、退路を作る杖。

- コマンドID：`neronoir`
- モチーフ：NeroNoir9696
- 特徴：印への帰還と本人デコイで、退路を作る杖。
- 通常攻撃：♥×2.5（補充後♥×3）。攻撃速度1.8回／秒。同じ相手へ5秒以内に4回当てると、4回目で真後ろへ回り込む。背中側から当てると+♥×1・盲目0.5秒。
- 右クリック：印を飛ばし、再使用で印へ帰還。
- シフト右クリック：本人デコイを10秒間展開。被弾時か終了時に発動地点へ戻る。
- CT：10秒（印への帰還・本人デコイで共有）
- 印：毎tick0.3m、最大48m。20秒残る。上向きは水平に補正し、安全を確認した会場内へ帰還。
- 本人デコイ：10秒間。自分は攻撃不可・被弾を防ぎ、被弾時か終了時に発動地点へ戻る。
- 反撃：デコイの攻撃者へ盲目・弱体化・発光5秒。

※固有武器は一人一個まで所持可能

**改善案（未実装・性能変更なし）：** 「印を置く」と「印へ戻る」を状態名と色で区別する。

## キリング：呪いの「き」マスク

視界を犠牲に、高速移動と確率防御を得るお面。

- コマンドID：`killing`
- モチーフ：F_KiRiSaN_1110
- 特徴：視界を犠牲に、高速移動と確率防御を得るお面。
- 装備効果：拾うと頭へ強制装着。移動速度＋175%・体力の上限が半分、盲目と大音量。最寄りの敵を発光表示。すべてのダメージを20%で無効化。
- CT：なし／装着の累計45秒で消滅
- 常時効果：移動速度＋175%（標準の2.75倍）。体力の上限が半分（外すと戻る）。盲目と本人だけへの大音量。最寄りの敵を本人だけに発光表示。
- 防御：すべてのダメージを20%で無効化（参加者の攻撃・落下・安地外・災害など。/killと奈落は対象外）。成功時はパリィ音と粒子。
- 注意：通常は取り外せない。TNT鬼の間は装着しない。

※固有武器は一人一個まで所持可能

**改善案（未実装・性能変更なし）：** パリィ成功を短い専用表示でも知らせ、ランダム防御の結果を伝える。

## ゆったり：瞬間奇襲アイテム

一瞬だけ敵の背後へ飛び込み、元の場所へ帰る奇襲武器。

- コマンドID：`yuttari`
- モチーフ：HitoriYuu
- 特徴：一瞬だけ敵の背後へ飛び込み、元の場所へ帰る奇襲武器。
- 通常攻撃：♥×2.5（補充後♥×3）。攻撃速度1.8回／秒。20%で相手を強く吹き飛ばす（スキルの半分の強さ）。
- 右クリック：ランダムな敵の背後へ転移して♥×0.5と強い押し出し（ノックバック1〜8のランダム）。1秒後に元の場所へ帰還。

※固有武器は一人一個まで所持可能

**改善案（未実装・性能変更なし）：** 発光・速度・盲目の対象を短く表示し、発動結果を理解しやすくする。
