# v1.9.208

- 採掘・チェストなどの医療品のドロップと更新後の所持品で、更新用データが異なりスタックできなくなる差を修正。同じ6種類の全コンポーネントを共通生成。ユーザー確認でスタックしない対象は小豆・包帯などの医療品。石炭の通常食料は採掘品とチェスト品の設定一致を確認。
- 小豆など医療品6種は「効果」のみとし、通常攻撃・右クリック・CT欄を削除。併用可能な消耗品の注記は「※固有武器と同時に所持可能。」へ統一。
- マップの到着予定マーカーは「補給物資」、着地後は「補給物資 第X便」。
- ほちきすの出血を毎秒2ダメージ（ハート1個、従来の軽減処理を維持）×2秒へ変更。説明は「出血を2秒間付与。」にし、出血のダメージ数は表示しない。

対応：データパック1.9.208＋プラグイン0.27.0＋リソースパック1.9.43（変更不要）。/oaplugin update apply で再起動して反映。会場・ロビー・練習場の再生成不要。既存所持品の説明・データは順次更新、既存チェスト品も取得後に更新。

検証：静的検査・ビルド・起動確認。試合の自動テストは指示で省略。実際の採掘・スタック操作・マップ描画・戦闘ダメージは未確認。
