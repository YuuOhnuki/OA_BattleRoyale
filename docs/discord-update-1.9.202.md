# v1.9.202 ロビー刷新

- ロビーを出撃ターミナルへ全面刷新。81×81の既存範囲に白い屋根・天窓・木の梁・植栽・水景・展示室・戦績ギャラリー・庭・テラスを再構成。
- 帰還位置を中央へそろえ、前方7ブロックにマップ・ゲーム・チームの受付。右クリックで同じメニューへ接続し、奥の案内板はモード・会場・人数・チーム状況を更新。
- 一般メニュー /oa を追加。参加・観戦・チーム・TDM武器・練習・戦績・実績・案内本を整理。ホストの設定は /oa host、管理者の保守は /oamenu。/tdm は武器選択に統一。
- 一般案内本を短い7ページ、管理本を最大5操作ずつの24ページへ再生成。管理本の初頁は取得時点の状態と主要メニュー。従来の管理番号・保存ID・チーム希望を維持。
- 管理画面を7分類へ整理。中止・生成・削除・更新は別の確認画面を経て実行し、権限や状態の変更を実行時にも確認。

導入：データパック1.9.202＋プラグイン0.21.0＋リソースパック1.9.41。両方を配置して /oaplugin update apply で再起動後、試合停止中に管理者が /trigger oa.admin set 14（または /oamenu のロビー再建）を実行。登録原点からX/Z±40、Y−3～+44の81×81範囲が再建され、ロビーの手編集は上書き。BR/TDM会場・練習場の再生成不要。旧ロビーは明示的な再建まで自動で書き換えない。

検証：静的・ビルド・起動とテスト用ワールドの建築生成。試合の自動テストは指示で省略。ブロック再構成の俯瞰で造形を確認。Minecraftクライアントの昼夜の実画面・本の実ページ収まり・メニュー操作・歩行は未確認。
