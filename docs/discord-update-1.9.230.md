# v1.9.230（新マップ：天空都市・異界）

新しいマップが2つ増えました！（全5マップ）

**☁ 天空都市**
空に浮かぶ島々の戦場です。中央には城壁と塔に囲まれた**天空城**（隠し通路あり）、まわりには森・廃墟・庭園・見張り塔・集落・神殿などの島が浮かび、橋でつながっています。
・橋は石橋・木の橋・吊り橋・崩れかけの橋（切れ目を跳んで渡る）
・**ジャンプ台**と**転移装置**（泣く黒曜石の床。乗ると遠くの島へ）
・**落ちたら奈落**。橋の下には救済用の足場と、上へ戻れる**上昇気流**があります

**🌌 異界**
崩壊した異界の文明が浮かぶ、紫と黒の世界です。中央には黒曜石の巨柱に囲まれた**異界神殿**（地下の遺跡あり）。黒曜石の森・崩れたエンドシティ・結晶の洞窟・異界の塔などの島があります。
・**異界ポータル**で離れた島へワープ
・**重力異常エリア**では体が軽くなり、高く跳べます
・こちらも落ちたら奈落です

**どちらも、試合のたびにまわりの島の中身（種類・建物・チェストの場所）が変わります。**
試合中の地図にも、その回の島の名前が出ます。
