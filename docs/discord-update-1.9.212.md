# v1.9.212（災害の拡張）

**災害が少し起こりやすくなり、ときどき重なるようになりました**
- 災害の発生の機会がおよそ25%増えました。
- ときどき2種類（20%）・3種類（5%）が同時に起こります。知らせはまとめて1回、内容はチャットに全部出ます。
- すべての災害に危険度（★1〜5）が付きました。起きている災害と残り時間は、画面上の赤いバーに出ます（武器やCTの表示はそのまま）。
- 災害が重なっているときは、災害による継続ダメージが1秒に♥×2までに抑えられます。

**新しい災害**
- 重力異常 ★★☆☆☆（15秒）：体が軽くなり高く跳べる。落下ダメージなし。
- ニワトリ大量発生 ★☆☆☆☆（12秒）：ニワトリが大量に走り回る。害はなし。
- 血の月・強制パーティー ★★☆☆☆（15秒）：全員が光り、頭上に花火。居場所が丸見え。
- 竜巻 ★★★★☆（15秒、地上・ネザー）：近くの人を吸い寄せて打ち上げる。ダメージ・落下ダメージはなし。
- ブタの大行進 ★★☆☆☆（15秒）：ブタが走り回り、ときどき小さく爆発（近くにいると♥×1）。

たやゆゆのガチャ「災害コンボ」は、新しい災害も含めて、そのマップの災害がすべて同時に起こります。
