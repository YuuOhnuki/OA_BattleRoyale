# v1.9.198 補給とたやゆゆ・ゆーの調整

- 第1便からすべての補給物資に固有武器を必ず1個。
- 元気百倍：最初の10秒だけ、試合中の全生存者が発光（使用者の45秒強化は従来どおり）。
- TNT鬼：継続中は全生存者が発光。
- ゆー：手に持たず、インベントリ内にあれば致死時に1個を自動消費して発動。手のトーテムとの二重消費は防止。

対応：データパック1.9.198＋プラグイン0.18.0＋リソースパック1.9.41。両方の配置後にサーバー再起動。会場・ロビー・練習場の更新は不要。

検証：静的検査・ビルド・起動チェック。試合の自動テストはユーザー指示で省略。実際の拾得・致死時の発動・発光の見え方は未確認。
