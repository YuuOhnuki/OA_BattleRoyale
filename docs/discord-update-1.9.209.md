# v1.9.209

- ほちきす #851c1c、ぴちぴち #2529ff に文字色を戻す。白縁は使用しない。
- 武器展示室の展示列を入口から移動し、入口前のベンチを移設。正面通路の幅と頭上の空きを生成時に検査。赤青の端末を背面パネルと同じ位置へ揃え、各色の参加者名を別々の縦リストで表示（待機中は希望、試合中は所属）。
- 「服は使い捨てですわ～」へ修正。同じ実績IDを維持し、破損した実アイテムをPaperのイベントで確認。通常の防具のみ対象とし、固有装備や時間切れ消滅・練習・チームデスマッチは対象外。既存の解除履歴は維持。
- 練習場の通常装備30種を実際のBRドロップ表から生成。鉄の槍を含み、ダイヤ斧・ネザライト・トライデントを除外。固有武器12種と通常装備の展示を右クリックすると本人のインベントリへ直接入る（空きがなければ配布しない）。武器用ボタンを除去し、旧メニューの不適切な取得経路も制限。練習前後の荷物保存・復元は維持。
- 前回結果に本人のスキンのプレイヤー模型を表示（1〜3位は表彰台、4位以下は小型展示）。UUIDを保存済み記録から取得し、オンラインのスキンまたは非同期取得のスキンを使用。重複を防ぎ、記録変更・削除時に模型を更新。人物のメニュー／実績のヘッドへ本人のプロフィールを設定。
- いとりの通常紫弾の命中箱を一辺1.25mから0.625mへ半減し、表示される弾を中心とする形へ修正。移動・射程・ダメージは維持。
