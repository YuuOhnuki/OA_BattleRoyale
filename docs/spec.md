## 1. 概要

友人同士で繰り返し遊ぶためのバトルロワイヤル。探索で装備を集め、友人をモチーフにした固有武器で戦う。

| 要素 | 内容 |
|---|---|
| 試合 | ソロ（1〜10人）またはチーム戦（1チーム最大3人、2チーム以上、最大10チーム） |
| 会場 | 地上 `br`（ディメンション `oa:br`）とネザー `nether`（`oa:br_nether`）。各 約305×305 |
| ロビー | オーバーワールド。参加登録・チーム選択・マップ選択・戦績ボード・練習場の入口 |
| 練習場 | ディメンション `oa:practice`。待機中だけ入れる。本試合と状態を分離 |
| 固有武器 | 友人モチーフ10種（1人1個まで）＋ 枠外の「ゆー：オーバーワーク」「ふろっしゅ：ふろボール」 |
| 試合中のイベント | 円形の安全地帯の収縮（1.9.218〜。赤い幕の壁、プラグイン）、チェスト上位化、空中補給3回、地面の固有武器、災害、封印の宝珠、今回のお題、終盤演出 |
| 永続要素 | 実績68種、通算戦績（ロビーの戦績ボード） |

### 1.1 設計の原則

- 装飾・建物は移動と戦闘を妨げない。ぴちぴち等の移動能力で登れて一方的に有利になる足場を作らない（垂直の壁・柱が中心）。
- 本試合・ロビー・練習場の状態を分離する。試合終了やガチャが、練習中の人の装備・効果を変えない。
- 既存の保存ID・管理コマンド（`oa.admin` のコード番号）・実績IDとの互換性を保つ。

### 1.2 構成と名前空間

| 名前空間 | 役割 |
|---|---|
| `oa` | 本体（関数 約2,780個、実績、戦利品表、ダメージタイプ、ディメンション、バイオーム、述語、タグ） |
| `oa_map2` | マップ生成の内部（ストラクチャ） |
| `jumppad` | ジャンプ台 |
| `minecraft` | 戦利品表・タグの上書き |

独自ダメージタイプ（`data/oa/damage_type/`）：`zone`（エリア外）、`ambush`、`bleeding`、`execution`、`flins_lightning`、`gacha_critical`、`gacha_penalty`、`itori_magic`、`sonic`、`yuua_counter`。

## 3. 試合の流れ

### 3.1 参加とチーム選択（待機中）

- ロビーの範囲に入ると自動で参加登録（`br/join`）。観戦者・練習中の人・試合参加中の人は除く。`/trigger br.join` `br.leave` でも登録・解除できる。**参加しない**（案内の本「参加しない（ロビーで待つ）」＝`oa.lobby 3`→`br/sit_out`、または `/trigger br.leave`）と、印 `br.optout` が付き、ロビーに入り直しても自動では登録しない（練習場にいてもよい）。メニューでチームを選ぶ・「試合に参加」・`/trigger br.join` で外れる（1.9.186）。
- チームは正面右の受付または /oa team から選ぶ。試合前・練習場の外で本人の希望を変更する。

| チーム | 識別色 | 名前の色 |
|---|---|---|
| 1 | ピンク | light_purple |
| 2 | シアン | aqua |
| 3 | 赤 | red |
| 4 | 青 | blue |
| 5 | 黄緑 | green |
| 6 | 黄 | yellow |
| 7 | 紫 | dark_purple |
| 8 | オレンジ | gold |
| 9 | 白 | white |
| 10 | 黒 | dark_gray |

- チーム `oa_br1`〜`oa_br10`：味方への攻撃なし（friendlyFire false）、ネームタグは他チームから非表示（保護期間中も同じ。1.9.160 までは保護期間中は誰にも見えなかった）。表示は名前の色だけで、「 - 色名」の接尾辞は付けない。
- ソロ戦は `oa_brsolo` に入る（復活・途中参加の人も入れ直す）。保護期間中もこのまま（1.9.185 まで、ソロの保護期間は全員を `oa_brgrace` に入れていた）。
- 選んだチーム（`br.pick`）は試合のあとも保ち、ロビーに戻ると同じチームに入り直す（1.9.185。`br/team/sync` を後片付けの完了・持ち物の復元のあとに呼ぶ）。登録を解除（`br.leave`）すると未選択に戻る。
- 保護期間（`br.pvp_grace`）中のプレイヤー同士のダメージ（近接・飛び道具・`damage … by`）は、プラグイン（0.9.0〜）が止める（ソロ・チーム戦とも）。固有武器は各処理で `br.pvp_grace` を見る。耐性 V も従来どおり付ける。

### 3.2 開始の操作

- `br.host` または登録管理者が /oa host からBRソロ・BRチーム・TDMの開始を選ぶ。旧ロビーでは手動更新まで従来の開始パッドも利用可能。
- 管理者は `oa.admin 5`（ソロ）／`6`（チーム）でも開始できる。

### 3.3 開始の検査（`br/start`）

次のどれかに当たると開始しない（理由をチャットに出す）：

1. 試合中である。
2. マップの生成・登録が終わっていない／会場の中心が未登録。
3. 復元待ちの参加者がいる／死亡中の参加者がいる。
4. 参加者が1〜10人でない。
5. チーム戦で、未選択の人がいる・4人以上のチームがある・チームが2つ未満。
6. 開始地点が足りない（ソロは人数分、チーム戦はチーム数分）。

検査を通ると、まず落とし物の清掃（状態4）を行い、済んだら次へ進む：練習場にいる参加者を `practice/leave` で戻す → 全員の持ち物を保存（`br/save_player`）→ 開始地点を決めてTP → 試合開始。

### 3.4 開始時の処理

- 参加者の初期化（`br/enter`）：持ち物を消去、アドベンチャー、体力・満腹を回復、経験値0。初期装備は**資源採掘用ツルハシ**（壊れない鉄のツルハシ。1.9.174 から、石炭・深層石炭・レッドストーン・深層レッドストーン・ネザー水晶・ネザー金の6種の鉱石を常に掘れる。以前は視線の先が登録された鉱石のときだけ壊せるブロックを書き換えていて、ラグで掘れないことがあった）のみ。
- 保護：耐性V（61秒）と `br.pvp_grace`。
- 地表への補正（`br/tp_fix`）：開始TPの直後と、3tick後から10tickごとに計7回、ブロック単位にそろえた高さで地表判定（足元が固体、体の2マスが空き）をする。体が埋まっていれば真上の最初の立てる場所へ（最大80ブロック上まで。移したら管理者に通知）、少し浮いていれば真下の地表へ（最大4ブロック）移す。途中参加（`admin/players/live_join`）も、TPの直後と同じ間隔で補正する（1.9.180）。
- ゲームルール：自然回復ON、即時リスポーンON、実績メッセージOFF（いずれも終了時に元へ戻す）。即時リスポーンと実績メッセージは、ロビー（オーバーワールド）と会場3つの全部に設定し、終了時はロビーの開始前の値に戻す（1.9.184。以前は試合を開始した人のいるワールドだけで、会場では効いていなかった）。自然回復は未対応（会場はもともと既定のON）。ロケーターバーは常にOFF（全ディメンション。1.9.183。Paper ではゲームルールがワールドごとなので、ディメンションごとに設定する）。
- 今回のお題の抽選、初心者サポート（実績「初陣」未解除の人に「ゆー：オーバーワーク」1個とヒント。1.9.243）、封印の宝珠の配置、災害の抽選の初期化。
- 観戦者（`br.watch`）はスペクテイターで会場の中心へ。
- 開始の案内（`br/intro`）：「ソロ戦 | 参加N人」（チーム戦は「チーム戦 | 参加N人」）、「探索して装備を集め、最後まで生き残ろう。」、「開始後6分でチェストが再補充されます。」

### 3.6 安全地帯（安置、1.9.218 から円形・プラグイン）

- **プラグインの `zone/SafeZoneManager`** が中心・半径・収縮・安置外ダメージ・赤い粒の壁・知らせを持つ。データパックは表示と補給の位置に使う値を読むだけ（下の「データパックへの値」）。1.9.217 までのデータパックの正方形の安置（`br/zone/*` の計算・壁・ダメージ、`br/phase/notify`）とワールドボーダーの縮小は削除した。
- **ワールドボーダーは試合中も300（マップの大きさ）のまま**動かさない（安置はボーダーで止めない。境界は自由に通れる）。
- **形と判定**：円。中心 (cx, cz)・半径 r に対し、(x−cx)²＋(z−cz)² ≦ r² なら内側（境界ちょうどは内側。平方根を使わない）。
- **時間**：データパックの試合時間 `#time br.time`（tick）を基準にする。開始のカウントダウン中は止まり、TPS が下がればゲーム全体と同じく遅く進む（実時間ではない）。半径と中心は収縮中、毎 tick 線形に補間（radius(t) = 開始の半径 ＋（目標の半径 − 開始の半径）× 進み具合）。
- **時間割（既定）**：今の補給の予告・着地（195〜225・315〜345・435〜465秒）、災害、終盤（540秒）と重ならないよう、これまでの縮小と同じ時刻にした（依頼の時間割 1:00〜7:40 は補給の着地と重なるため）。`config.yml` の `safe-zone.shrink-phases`（開始秒:長さ秒:目標半径:安置外ダメージ〔HP、♡1つ＝2〕）で変えられる。

|---|---|---:|---:|
| 0:00〜2:00 | 最初の待機 | 215 | （♡×0.5。四隅まで入るのでふつうは外に出られない） |
| 2:00〜3:00 | 第1収縮 | 215→150 | ♡×0.5 |
| 3:00〜4:00 | 待機 | 150 | ♡×0.5 |
| 4:00〜5:00 | 第2収縮 | 150→95 | ♡×1 |
| 5:00〜6:00 | 待機 | 95 | ♡×1 |
| 6:00〜7:00 | 第3収縮 | 95→55 | ♡×1.5 |
| 7:00〜9:00 | 待機 | 55 | ♡×1.5 |

| 11:00〜 | 最終安置 | 10 | 4 |

- **中心の移動**：各収縮の目標の中心は試合の初めにまとめて決める（収縮の前に確定）。乱数の種は試合の番号（`#round br.round`）とマップの中心なので、試合中にサーバーが再起動しても同じ時間割に戻る。次の中心までの距離は（今の半径 − 次の半径）× 0.85 以下（次の安置は今の安置に必ず入る）、次の中心はマップの正方形（半辺150）の内側に次の半径ぶん入る（はみ出さない）。地上・ネザーでは、読み込み済みのチャンクで最上面が水・溶岩・空気になる中心を8回まで選び直す（地形は変えない）。**プラグイン 0.37.0 からの既定は中心を動かさない**（中心はマップに登録した中心 `oa:br center` のまま、同心円で縮む）。上の移動は `move-center: true` のときだけ。
- **安置外ダメージ**：試合中の生存者（タグ `br.alive`・`br.playing`、サバイバル／アドベンチャー、練習中でない）が対象。会場のディメンションの外（ロビーなど）にいる生存者は常に外。外に出てから **2秒（`damage-grace-ticks` 40）** は受けない（押し出されてもすぐ戻れば助かる。これまでと同じ）。そのあと20 tick ごとに、その段階の量（毎秒×間隔/20）を `damage`（ダメージの種類 `oa:zone`）で与える。`oa:zone` は防具・エンチャント・耐性・盾・無敵時間（クールダウン）を無視する種類なので、ほかのダメージの直後でも欠けない。ノックバックはしない（`#minecraft:no_knockback`、1.9.224）。代わりに、地上なら向きのない小さな跳ね上がり（上向き0.2）と棘の音で「ペチッ」とした手応え（プラグイン 0.40.0）、ダメージが入ったときは画面の揺れ（`sendHurtAnimation`、向きはランダム。0.42.0）。外に出た瞬間に本人にだけ大きめの警告音（0.38.0）、外にいる間は警告音を鳴らし続ける（0.40.0 は1秒ごと、0.41.0 から0.5秒ごと）。倒れると通常の死亡・脱落・観戦・キルログ（「〜 は エリアの外 で倒れた」）。**保護期間（タグ `br.pvp_grace`）中は受けない**。安置内に戻るとすぐ対象から外れる。観戦者・ロビー・ほかのワールドの非参加者は対象外。
- **粒の壁（プラグイン 0.37.3 から既定 `wall-style: particles`）**：赤（255,35,35）・薄い赤（255,140,140）・白（255,255,255）の3色の斜めの縞（0.37.5。`particle-colors` で1〜8色）。粒は大きさ1.3、横約0.8・縦約1ブロックの間隔、1人1回900まで（0.37.2 までの約2倍の密度）。縞は円周上の角度に固定し、時間とともに横へ流れる（収縮中は速く）。地面の線・次の安置の点線・安置外の画面の赤みは見せ方によらず出す。
- **赤い幕の壁（`wall-style: curtain`、0.37.0〜0.37.2 の既定）**：背景を半透明の赤（RGB 255,40,40、濃さ80/255）にした text_display を、円周に沿って幅8ブロックの板で、重ねずに端を接して並べる（0.37.1）（高さは本人の上下12ブロック、2ブロック刻みで追う）。本人から48ブロック以内の弧だけ・1人40枚まで、**その人にだけ**見せる（visibleByDefault=false、保存しない、タグ `oa.zone_wall`）。板の表は本人の側へ向ける。動くときは表示側の補間で滑らか。あわせて、壁が地面に接する所に明るい粒の線、次の安置の境目に白い点線（足元付近の床を探すので洞窟・ネザーでも天井に出ない）。安置外の生存者には、その人にだけ送るワールドボーダー（中心・大きさは本物と同じ、警告の距離だけ大きく）で画面の縁を赤くする。
- **赤い粒の壁（`wall-style: particles`、0.36.0 の見せ方）**：`Particle.DUST`（RGB 255,45,45、大きさ1.1）。円周全体は描かず、プレイヤーごとに、描画距離（32）以内に入る円周の弧を余弦定理で求め、その人の高さの上下12ブロックに、横約1.5・縦約2ブロックの間隔で、5 tick ごとに、**その人にだけ**送る。境界から32より遠い人には描かない。1人1回の上限400（超えるときは間隔を広げる）。境界から遠いほど横の間隔を最大2倍に。演出（`particle-effects`）：粒がゆっくり上へ流れる、収縮中に明るい粒が混ざる、安置外の自分の周りに赤い粒。設定で密度・距離・頻度・上限・高さ・色・大きさ・演出を変えられる。
- **表示**：アクションバー（データパックの `br/ui/actionbar`）は、武器名・CT・味方の表示を残したまま、中では「境界まで Xm」、外では「⚠ 安全地帯の外です！」だけ（1.9.220 から距離・ダメージの量は出さない）。サイドバーは「安置の半径： 55m」「フェーズ N - 待機中／収縮中／最終安置」「次の収縮： m:ss」。地図（試合中の地図）は今の安置を赤い円、次の目標を白い円で描く。

### 3.7 時刻と天候

- 時刻：試合開始時に正午（6000）にして、以降は通常の**4倍の速さ**で進む（5分で1日。tick 3000 前後で真夜中）。終了時に元の時刻へ戻す。ネロノワールの夜補正（§7）に影響する。
- 天候：マップ定義が `weather:1b` のマップ（地上）だけ。開始時は晴れ。tick 3600 から3分ごとに抽選：**晴れ70%・雨20%・雷雨10%**、結果をチャットで通知。終了時に元の天候へ戻す。ネザーは天候なし。

### 3.8 脱落・観戦・離脱

- 体力0で脱落（`br/eliminate`）：スペクテイターになり、会場の中心へ。全参加者に「〜が脱落しました」。最初の脱落者は隠し実績「開幕ダッシュ失敗」。
- 試合中に退出した生存者は、持ち物をその場に落として脱落扱い（`br/surrender`）。
- 観戦：脱落者と観戦者は `/trigger oa.spec`（1=次の生存者、2=前の生存者、3=自由視点）またはチャットのボタンで視点を切り替える。脱落直後は自由視点のまま（自動では追従しない）。スニークで視点を外せる。試合終了で解除。
- 会場の外（ロビー等）に出たスペクテイターは、毎秒の確認で会場の中心へ戻す（練習中の人は除く。本人のいるディメンションで判定）。
- チーム戦では、アクションバーに生存中の味方の名前とXYZ座標を常に出す。

### 3.9 勝敗と終了

- 毎秒、生存者を数える（`br/check_winner`）。
  - 生存者0人 → 引き分け。
  - ソロで生存者1人 → その人が優勝。
  - チーム戦で生存チーム1つ → そのチームが優勝。
  - **参加者が1人の試合は自動では終わらない**（テスト用。管理者が `oa.admin 7` で終了する）。
- 優勝：タイトル・チャット、実績「最後の一人」とマップ別の優勝実績、リザルト表示、祝賀（優勝者の位置で花火4回）→ 6秒後に終了処理。
- 終了処理（`br/finish`）：補給・終盤演出・災害・宝珠・飛翔体などの削除、ボーダーと時刻・天候・ゲームルールを戻す、参加者の持ち物を復元してロビーへ、**参加登録とチーム選択を未所属に戻す**、ロビーの戦績ボードを約1秒後に更新。
- 管理者の中止：`oa.admin 7` または `/function oa:br/stop`。

## 5. 災害と封印の宝珠

### 5.1 災害の進行（1.9.212 から複数同時）

- **定義は1か所**：`scripts/gen_disasters.py` の `DISASTERS`（番号・キー・表示名とマップ別の呼び名・色・危険度・秒・抽選の重み・出るマップ・説明）。このスクリプトが、抽選（`disaster/pick`・`available`）・予告（`announce`）・開始（`go/kN`・`start_planned`）・1秒ごとの進行（`run/kN`・`run_all`）・終了（`stop/kN`・`halt/kN`）・ボスバー（`bar`）・管理者用の関数・初期設定（`cfg_defaults`）を生成する。災害の中身は手書きの `disaster/k<N>/start`（任意）・`second`（必須）・`end`（任意）。災害を足すときは、表に1行足して中身を書き、スクリプトを実行する。
- **設定**（ストレージ `oa:disaster cfg`。初期値は `cfg_defaults`、`cfg.v` が212でないときだけ入れ直す。ゲーム内で `data modify storage oa:disaster cfg.<名前> set value …` で変えられる）：`cd_min`・`cd_max`（前の災害がすべて収まってから次の抽選までの秒、50〜75）、`first_min`・`first_max`（試合の最初の災害まで、保護期間の終わりから30〜45）、`multi2`・`multi3`（同時に2種類・3種類になる確率%、20・5）、`weight.kN`（抽選の重み。0で出ない）、`dot_cap`（同時発生中の1人1秒の継続ダメージの上限、4）、`mob_cap`・`chicken_cap`・`pig_cap`（災害の動物の上限、60・40・30）。
- **頻度**：試合中、tick 1200〜10200 の間。前の災害がすべて収まってから50〜75秒後（1.9.211 までは70〜110秒）、最初は保護期間の終わりから30〜45秒後（同 50〜80秒）に抽選。合図がエリアの縮小・空中補給の知らせと重ならない時間帯の規則（`disaster/busy`、1.9.161）はそのまま。
- **同時に起こる数**：発生が決まったら、1種類75%・2種類20%・3種類5%（`multi2`・`multi3`）。このマップで起こる災害から、重みで**重複なく**選ぶ。前回起きた災害はなるべく避ける（足りないときは避けずに選ぶ）。それぞれ自分の残り秒（`#dsN br.tmp`）で独立に進み、独立に終わる（終わるときはその災害の効果だけを外す）。互換のため `#dis_kind br.tmp` は起きている中で一番小さい番号。
- **予告**：雷の音とチャットで、災害ごとに「⚠ 災害発生：名前　危険度（秒数）」と説明を通知する。タイトルは数・種類によらず共通の「⚠ 災害発生」（サブタイトル「内容はチャットを確認」）。単発・複数・災害コンボも同じ形式で、タイトル/サブタイトルは出さない。**5秒後に一斉に始まる**。発生の3秒前から1秒ごとに効果音。
- **起きている間**：ボスバー `oa:disaster`（赤）に、起きている災害の名前・危険度・残り秒をまとめて出す（アクションバーの武器名・CT・境界の距離は消さない）。災害によるアクションバーの変更は行わない。1つ収まるたびに「✔ 〈名前〉 が収まった」、全部収まると「✔ 災害がすべて収まりました」。
- **継続ダメージの一元化**：災害の継続ダメージは `disaster/dmg {amount,type}` を通す。2種類以上が同時に起きている間（災害コンボを含む）は、1人あたり1秒の合計を `dot_cap`（4）までに抑える。1種類のときは本来の威力のまま。隕石群の着弾は継続ダメージではないので対象外。
- **片付け**：試合の終わり・中止（`disaster/clear`）は、すべての災害を止め（それぞれの `end` を実行）、印・災害の動物・竜巻・ボスバー・全員の災害の効果を消す。脱落（`br/eliminate`）とログイン（`lobby/on_login`）は、その人の災害の効果（重力・跳躍・落下無効）を外す（`disaster/player_clear`。起きている災害は次の1秒で付け直す）。
- **管理者用**（試合中）：プラグイン 0.41.0 から `/oaplugin disaster list|start <名前>|now <名前>|multi <n>|combo|stop|auto on|off`（名前は tornado・竜巻・10 など、Tab で候補）。関数でも：`oa:disaster/admin/start {k:4}`（その災害を5秒後に）、`admin/multi {n:2}`（このマップの災害から n 種類を抽選）、`admin/combo`（災害コンボ）、`admin/stop`（全部止める）、`admin/list`（一覧・重み）。通常の抽選を止めるのは従来どおり `/scoreboard players set #dis_off br.tmp 1`（起きている災害は最後まで進む）。
- **自動テスト**：`tools/disaster_test.py`（テスト用サーバー、偽のプレイヤー4人の地上ソロ戦。1種類ずつ・2種類・3種類・災害コンボ・試合の中止の片付け）。

### 6.5 開始地点

- マップごとに保存（ストレージ `oa:spawn_points`）。管理ブックのマップ別ページ（地上 67〜70、ネザー 87〜90）で追加・確認・削除・全削除。そのマップのディメンションに立っているときだけ登録・削除できる。メッセージには「【地上（草原と雪原）】」のようにマップ名を付ける。
- 登録・配置の条件：足元が通り抜けられないブロックで、`#oa:spawn_unsafe_floor`（溶岩・火・水・クモの巣・マグマ・サボテン・焚き火・粉雪・鍾乳石・スイートベリー・ウィザーローズ）でない。頭上2マスが通れる。周囲の足元4点も検査。
- 登録する高さ（`br/spawn_points/add_find`）：x・z はブロックの中心、y は足の高さを切り捨てた値から始めて、立てなければ1つ上（高さが1に満たない床：土の道・ハーフブロック・ソウルサンドなど）、1つ下・2つ下（ジャンプ中）の順に試し、最初に立てた高さで登録する。
- `br/spawn_points/verify` は常に成功を返す（登録済みの地点を信用する）。地形とずれた地点（会場の再生成や起伏の変更の前に登録したもの）は、開始TP後の地表への補正で救う。

## 7. 固有武器と装備

### 7.1 共通ルール

- 表示名は「人の名前：二つ名」（固有枠外の「ゆー：オーバーワーク」も同じ形）。

## 14. 運用

- `main` への push で、self-hosted runner がサーバーのデータパックを差し替えて `/reload` する（試合中は保留。`docs/server-autoupdate.md`）。
- 反映の種類：関数だけの変更は `/reload`。会場の変更は再生成。ロビーの建物の変更は `oa.admin 14`。練習場の変更は練習場の再建築。
- リソースパックは各プレイヤーが ZIP のまま入れる（`OA_BattleRoyale_Resources_v1.9.36.zip`）。
- サーバー側で `allow-flight=true` が必要（「Flying is not enabled」での切断対策）。
- 静的検査：`python3 tools/check_release.py .`（Windows では `py -3`。JSON・関数の参照先・コマンド名・版数表示のそろい）。マクロ関数（`$` 行）の参照先と、コマンドの引数の正しさは検査に出ない。
- 自動更新は、反映後のサーバーログに関数の読み込みエラーがあると前の版へ巻き戻し、その版（コミット）を `badSha` として再試行しない。**読み込みエラーが1件でもあると本番に入らない**ので、push 前に静的検査を通す。サーバー上の `autoupdate/update.ps1` はリポジトリから自動では更新されない。

## チームデスマッチ（TDM、v1.9.201）

### 1.9.212 災害の拡張

- 災害の定義を1か所に（`scripts/gen_disasters.py` の表：番号・表示名・危険度・秒・重み・出るマップ・説明）。抽選・予告・開始・1秒ごとの進行・終了・ボスバー・管理者用の関数を生成する。設定はストレージ `oa:disaster cfg`（間隔・同時発生の確率・重み・継続ダメージの上限・動物の上限）。
- すべての災害に危険度（★1〜5）：酸性雨4・寒波4・隕石群5・毒霧4・地震3・濃霧2・重力異常2・ニワトリ1・血の月2・竜巻4・ブタ3。発生時のチャットに危険度と説明、起きている災害と残り秒はボスバー `oa:disaster`（アクションバーの武器・CT・境界はそのまま）。
- 発生の機会を約25%増：前の災害が収まってから次の抽選まで 70〜110秒→50〜75秒、最初は保護期間の終わりから 50〜80秒→30〜45秒。縮小・補給と重ならない規則・持続時間は変更なし。

- 新しい災害5種類：重力異常（20秒）・ニワトリ大量発生（20秒）・血の月（30秒）・竜巻（20秒、地上・ネザー）・ブタの大行進（15秒、爆発で♥×1、同じ人へ2秒に1回）。竜巻の動き・吸い寄せ・打ち上げと動物の走り回りはプラグイン（`disaster/DisasterService`）。依頼の「6種類」のうち内容が書かれていたのは5種類。
- 災害コンボ（たやゆゆのガチャ）は新しい災害も含めて、そのマップの災害をすべて同時に。同時発生中の安全制御：災害の継続ダメージを1人1秒♥×2（`dot_cap` 4）まで、動物は合計60（ニワトリ40・ブタ30）まで、竜巻の打ち上げは3秒に1回・重力異常中は弱め、重力異常の浮遊は竜巻で打ち上げ中の人に掛けない。
- 片付け：試合の終わり・中止で全災害の終了処理・動物・竜巻・ボスバー・全員の災害の効果を消す。脱落・ログインでその人の災害の効果（重力・跳躍・落下無効）を外す。

対応：データパック1.9.212＋プラグイン0.31.0＋リソースパック1.9.43（変更なし）。**両方をそろえて** /oaplugin update apply で再起動して反映（データパックだけだと竜巻が動かず、動物も走らない）。会場・ロビー・練習場の再生成は不要。

- ロックオンで撃った矢の速さを50%に（撃ったときの速さの半分、最低0.6）。矢のダメージは速さに比例するので基礎ダメージを割り戻し、ダメージは今まで通り通常の75%。曲がって飛ぶ時間は6秒まで。
- ロック中の演出を大きく：相手のまわりを回る赤い2重の輪・照準の角（縦の線4本）・頭上の大きな印。完了の瞬間に赤い粒の破裂。

## 1.9.249

- **ゆうあの攻撃を盾で防げるように**：帽子をかぶった人の攻撃（近接・飛び道具とも）を盾で防いだときは、一撃で倒れない（進捗 `oa:yuua/struck` のダメージ条件に `blocked: false`）。帽子をかぶった人を攻撃したときの反撃（社会的制裁）は今まで通り。
- **らじの音波を足もとから高さ4m・半径4mの円柱に**（1.9.248 の上下6mは、上下に広く音符の輪の形も球のように見えていた）。体（高さ1.8）が少しでも円柱に入っていれば当たる（足の高さの差が -1.8〜4.0）。音符の輪は小・中・大とも同じ高さ5段（0〜3.9m）で、大きい輪には側面の縦線8本。

## 1.9.250
