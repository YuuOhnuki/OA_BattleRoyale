# OA Battle Royale 仕様書（1.9.137 時点）

## 1. 試合ルール
- 最大10人。ソロまたは固定2〜3人チーム（チーム oa_br1〜oa_br10）。
- 開始：ホストが開始パッドに5秒立ち、最後の3秒をカウント。開始後60秒はPvP・環境保護。初期装備は採掘用ツルハシのみ。
- チェスト67個（塔4・洞窟2・海中遺跡2は特別チェスト。中身は上位表1：通常表3で抽選。時間経過による上位化は従来どおり）は6分に1回再補充。鉱石108か所：石炭=食料、レッドストーン=医療品。60秒で再生、採掘ごと2%で追加「ゆー」。
- 縮小（tick 2400/4800/7200/10800/12000）：一辺230/160/90/20/2、各60秒。最終円は中央広場。

- 終盤の演出は1.9.119で控えめに（花火は1回2発、パーティクル数と音量を約半分、閃光を廃止、地上の追加花火を廃止、ネザーは2回に1回のみ）。
- 終盤（tick 10800以降）: 開始時に全員へタイトル「★ 最終局面 ★」。演出はマップ定義の `finale`（関数ID）で決まる共通の仕組み（`oa:finale/tick`→`oa:finale/exec`。`finale` を省くと `oa:finale/default`）。地上＝`oa:finale/br`、ネザー＝`oa:finale/nether`（溶岩・炎・魂の火・灰のパーティクルと音。ダメージ・地形変更なし）。新マップは `map/internal/defs` に `finale:"oa:finale/<名前>"` を足し、その関数をマップ中心（x,y,z）で実行される形で作る（`#fstep` が0〜2を約0.4秒ごとに回る）。以下は地上マップの演出: 広場ドームのシーランタン56個と、広場の地面（中心から半径25以内）のシーランタン90個（OAロゴ含む）が点滅、約1.2秒ごとに4発の花火演出（色は6種からランダム、パーティクルと音のみ・ダメージなし）。高さは広場の地面から約+14〜+21で、ドームの内側。
- 空中補給（1.9.119で4回→3回）：予告 tick 4800 / 7200 / 9600（30秒前）→ 降下開始 tick 5220 / 7620 / 10020 → 着地 tick 5400 / 7800 / 10200。ボーダー内のランダムな地表へ、パラシュート付きの光る箱が高さ90ブロックから約9秒かけて降りてくる。予告時と降下時に、全員へタイトル表示、場所の名前（中央広場／北の雪原／東の森／西の住宅街／北の湖のまわり／南の草原／南の海辺）、座標、各プレイヤーからの方角と距離をチャットで表示。着地後は約30秒間だけアクションバーに方角と距離を毎秒表示（光る柱は約180秒間）。種類は3つ（抽選）：①バランス（特別チェスト表×2＋回復×1）②回復・食料（回復×3＋食料×1）③武器たっぷり（上位表×1＋特別チェスト表×1＋通常表×1）。
- 今日のお題：試合開始時に全員共通で1つ抽選（チェスト8個／1キル／6分生存／素手で1キル／ジャンプ100回）。達成で回復アイテム1個、実績『お題達成』『お題マスター（累計5回）』。`/trigger oa.mission` で確認。
- 初心者サポート：試合開始時に回復アイテム1個を配布しヒントを表示（`#nobeginner br.flag`=1で無効。`/function oa:admin/beginner/off` `on`）。
- 終了時リザルト：優勝発表のあと、参加者ごとにキル・与ダメ・移動距離・チェスト開封数を表示。続けて「ハイライト」（1.9.107）として、キルキング（最多キル）／ダメージ王／マラソンマン（最長移動）／トレジャーハンター（最多開封）／ジャンプ王／粘りの人（優勝者以外で最長生存）を表示。同数は全員を併記し、記録が0の項目は出さない。前回結果（`/trigger oa.result`）でも再表示される。
- 観戦（1.9.107）：脱落者と観戦者は `/trigger oa.spec`（1=次の生存者、2=前の生存者、3=自由視点）で生存者の視点へ切り替えられる。脱落直後に自動で最初の生存者へ付き、チャットのボタンでも操作できる。スニークで視点を外せる。試合終了時に解除。本試合中のみ有効。
- 実績（旧38種（隠し6を含む）→1.9.123で57種、試合をまたいで保持。管理者のみリセット可）：共通（初陣／ハットトリック／宝探し／最後の一人）、武器別（ぴちぴち『魚のまま20秒』＝敵の跳ねを20秒途切れさせない、キリング『25%の奇跡』＝攻撃を無効化、ゆうあ・lazi・ネロ・ゆったり・ほちきす・たやゆゆ・こまめ・ふろボール、各武器の初キル）。
  - 実績の構成（1.9.125、全57種・隠し11種）：進捗画面のOAのタブは1つ（`oa:ach/root`）。バニラのタブと順番が混ざらないよう、カテゴリはタブではなく枝（`cat_br`／`cat_map`／`cat_weapon`、自動で解除）にした。隠し実績は専用のタブを持たず、関連する枝の中に入る（解除するまで表示されない）。
    - バトルロワイヤル（`cat_br`）：初陣→ハットトリック→殲滅者（1試合5キル）／宝探し→大富豪（20個）／お題達成→お題マスター／常連さん（通算10試合）／最後の一人→連勝街道（通算3勝）→OAの王者（通算10勝）。
    - マップ（`cat_map`）：地上・ネザーそれぞれ「参加」→「優勝」、両方優勝で全マップ制覇。新マップは `ach/map_start`・`ach/map_win` と実績JSONを足す。
    - 固有武器（`cat_weapon`）：武器ごとに「初キル→固有の実績→マスター」の枝（いとりは初キル→マスター、ふろボールは爆風のみ）。
    - 隠し実績（11種）の置き場所：初陣の下＝拳で語る（素手でキル）／宝探し→大富豪の下＝強欲な探検家（1試合30個）／常連さんの下＝皆勤賞（通算50試合）／最後の一人の下＝平和主義者・紙一重・清貧の勝者・地を這う者／バトルロワイヤルの直下＝地平線の向こうへ・ウサギ跳び・開幕ダッシュ失敗／固有武器の直下＝武器博士。
    - 練習場（`oa.practice`／`oa:practice`）では `ach/give` が何も付与しない。既存実績のIDは変えていないので解除状況は引き継がれる。生成は `scripts/gen_ach_1_9_123.py`。
  - 武器別マスター（1.9.107、10種）：固有武器を装備したまま3キル連続（別の装備でのキルを挟むと数え直し）。ゆうあ『帽子の主』／ぴちぴち『大漁旗』／lazi『騒音の主』／ネロ『疫病神』／キリング『呪われし者』／ゆったり『影の暗殺者』／ほちきす『針山』／こまめ『豆台風』／たやゆゆ『ガチャの申し子』／いとり『いとりの申し子』。
  - 隠し実績（1.9.107、6種。解除するまで名前と条件が一覧に出ない）：平和主義者（0キルで優勝）／地平線の向こうへ（1試合3000m以上移動）／ウサギ跳び（1試合300回以上ジャンプ）／紙一重（体力1ハート以下で優勝）／開幕ダッシュ失敗（最初の脱落者になる）／武器博士（10種のマスターをすべて解除）。

## 2b. 複数マップ（1.9.108）
- マップ定義：`data/oa/function/map/internal/defs.mcfunction` の表（キー・ID・ディメンション・中心 x/y/z・center_y・タイル関数の場所・終盤演出 `finale`）。現在は `br`（ID 0、`oa:br`、地上）と `nether`（ID 1、`oa:br_nether`）。マップごとに専用ディメンション、ディメンションタイプ（`dimension_type/`）、時計・タイムライン、バイオーム（`worldgen/biome/`）を `oa` 名前空間で持つ。命名は `oa:br_<キー>`（地下は `oa:br_cave`、エンドは `oa:br_end` を予約）。
- 選択中のマップ番号はスコア `#map oa.mapid`。ディメンションを使う関数は、`scripts/multimap_expand.py` が `in oa:br` / `dimension oa:br` を番号ごとの分岐へ展開したもの（地上マップの動作は従来と同じ。再実行可、マップ追加時は表 `MAPS` に足して再実行）。
- コマンド（管理者）：`/function oa:map/select {key:"nether"}`（試合停止中のみ。開始地点・中心・生成状態はマップごとに保存し、切替時に読み戻す）、`oa:map/select_br`、`oa:map/select_nether`。生成は `/function oa:map/create`（選択中のマップを生成）、`oa:map/create_nether`（選択して生成）。再生成は `/function oa:map/rebuild`（選択中のマップ。既存の地上マップでは従来どおり）、`oa:map/rebuild_br`、`oa:map/rebuild_nether`。削除は従来の `oa:map/delete`（選択中）。ロビーでの投票は未実装。
- 試合終了時は、どのマップでも参加者をロビーへ戻し、チームを未所属に戻す（従来の処理を共通利用）。
- ジョブ：区画関数は `oa_map2:args.tiles` の場所から呼ぶ（地上は `oa:map/internal/tiles`、ネザーは `oa:maps/nether/tiles`）。

既存セーブ・管理コマンド互換。スコアボード版数は `oa:br/ui/version`。

## マップ別の管理コマンド（1.9.112）
- 試合用マップは `br`（地上）と `nether`（ネザー）。管理者のトリガー `oa.admin`：地上 60〜71、ネザー 80〜91（順に：中心へ移動／会場を生成／再生成／削除／現在地を中心に登録／生成した中心を使う／ボーダー自動設定／開始地点の追加・確認・削除・全削除／このマップを試合に使う）。
- 関数でも `/function oa:map/do {key:"br"|"nether",op:"teleport|create|rebuild|delete|center|gen_center|border|sp_add|sp_list|sp_remove|sp_clear|select"}`。別名：`oa:map/teleport_br`／`teleport_nether`／`create_br`／`create_nether`／`rebuild_br`／`rebuild_nether`／`delete_br`／`delete_nether`／`select_br`／`select_nether`。
- 中心へ移動は、選択中でなくても、登録済みの中心へ移動する（試合中も可）。それ以外は、そのマップを選択中にしてから実行する（試合中・生成中は切り替えられず、実行されない）。中心登録は、そのマップのディメンション内に立っているときだけ。
- 旧コマンド（3／13／29〜31／48／49／54〜57）は「選択中のマップ」が対象。`oa:map/status` に選択中のマップ名を表示。
- 管理ブック：地上・ネザー別ページを追加し、全コマンドを `admin/dispatch.mcfunction` と照合。`scripts/gen_admin_book.py` で生成する。

## 災害と封印の宝珠（1.9.128、1.9.133で改訂）
- 災害メッセージ（1.9.135）：開始のチャットとアクションバーに、実際のダメージ量を同じ書き方（毎秒N／N・M／動くと毎秒N）で載せる。酸性雨・寒波は毎秒2、隕石は半径3.5以内12・5.5以内6、毒霧は毎秒1＋毒II、地震は動くと毎秒3。
- アクションバー（1.9.133）：災害の警告は、影響を受けている本人にだけ、3秒ごとに通常のバーと交互に出す（警告3秒→通常3秒）。補給物資の表示中は通常側。
- 災害（`data/oa/function/disaster/`）：保護期間（60秒）のあと〜終盤の少し前（時刻10200tick）まで、試合中に不定期で1つずつ起こる。最初は保護期間終了の50〜80秒後、以降は災害が収まってから70〜110秒後。直前と同じ種類は連続しない（1回だけ引き直す）。発生時は画面タイトル・チャット・雷の音で知らせる。抽選される種類はマップ定義 `oa:maps defs.<key>.disasters` の関数（`oa:disaster/pool/<名前>`、無指定は `pool/default`）で決まる。
  - 酸性雨（地上のみ、30秒）：雨を降らせ、空が見える場所（足元の真上の最上面より0.9ブロック以上低くない場所。1.9.131で判定をコマンド方式に変更）で頭防具なしの生存者に、毎秒2ダメージ（魔法）。屋根の下・頭防具で無効。途中で天候抽選が晴れにすると、その時点でダメージも止まる。終了時に天候の目標を災害前へ戻す。
  - 寒波（地上のみ、30秒）：空が見える場所で革の胸当てなしの生存者に、毎秒2ダメージ（凍結）＋鈍足II。屋根の下・革の胸当てで無効。
  - 隕石群（全マップ、24秒）：毎秒、ランダムな生存者2人の近く（±8ブロック）に赤い円が出て、約3秒後に着弾。半径3.5以内12ダメージ、5.5以内6ダメージ（爆発）。ブロックは壊れない。
  - 毒霧（全マップ、40秒）：ランダムな生存者3人の近く（±12ブロック）に緑の霧が3つ出て、半径9以内で毎秒1ダメージ（魔法）＋毒II（毒だけでは致死しない）。
  - 地震（全マップ、10秒）：全生存者に吐き気・鈍足。毎秒、直前の1秒に歩く・走る・しゃがみ移動・ジャンプのどれかをした人に3ダメージ（落下）。止まっていれば無傷（統計 `br.qwalk` `br.qspr` `br.qsneak` `br.qjump` で判定。ノックバックやテレポートは対象外）。
  - 濃霧／灰嵐（全マップ、30秒）：全生存者に暗闇（視界が暗く狭くなる）。ネザーでは灰嵐の名前。
  - 抽選：地上＝上の6種、ネザー・標準＝隕石群・毒霧・地震・濃霧のみ（天候系なし）。
- 封印の宝珠（1.9.133。旧ギミックの間欠泉・癒やしの泉・火口は廃止）：試合開始時に、登録済みのチェスト（建物の中）のうちランダムな最大8か所の真上に、光る「海洋の心」（表示）と右クリック判定を置く。
  - 右クリックで5秒の解錠が始まる。解錠中は半径5以内に生存者がいる必要があり、いなくなると中断して封印に戻る（進行は失う）。
  - 解錠中は毎秒、光の柱（半径96）と鐘の音（半径48）が出て、場所が分かる。近くの生存者にはサブタイトルで残り秒数を出す（アクションバーは使わない）。
  - 完了すると、`oa:br/chest_site` と `oa:br/chest_upgraded` の戦利品がその場に出る。最も近い生存者（半径5以内）に再生II（8秒）と衝撃吸収II（20秒）。全員に「どこかで宝珠が解錠された」と知らせる（場所は伏せる）。
  - 宝珠は試合終了・中止時に削除する。マップは変更しない。
- 管理：災害の無効化 `/scoreboard players set #dis_off br.tmp 1`、宝珠の無効化 `#relic_off br.tmp 1`（0で戻る。次の試合から有効）。印は試合終了・中止・開始時に削除する。
- 新しいマップ：`defs` に `disasters:"oa:disaster/pool/<名前>"` を足し、その関数で `#dis_kind br.tmp` を1〜6から抽選する。
- 練習場や試合外では動かない（生存者タグ `br.alive` と試合状態1のときだけ）。

## 開始地点の登録条件（1.9.129）

## たやゆゆのハズレガチャ（1.9.130）
