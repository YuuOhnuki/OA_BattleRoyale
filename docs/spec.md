# OA Battle Royale 仕様書（1.9.102 時点）

## 1. 試合ルール
- 最大10人。ソロまたは固定2〜3人チーム（チーム oa_br1〜oa_br10）。
- 開始：ホストが開始パッドに5秒立ち、最後の3秒をカウント。開始後60秒はPvP・環境保護。初期装備は採掘用ツルハシのみ。
- チェスト67個（塔の上位チェスト4・洞窟2・海中遺跡2を含む）は6分に1回再補充。鉱石108か所：石炭=食料、レッドストーン=医療品。60秒で再生、採掘ごと2%で追加「ゆー」。
- 縮小（tick 2400/4800/7200/10800/12000）：一辺230/160/90/20/2、各60秒。最終円は中央広場。

- 終盤（tick 10800以降）: 広場ドームのシーランタン56個が点滅、約1.2秒ごとに4発の花火演出（色は6種からランダム、パーティクルと音のみ・ダメージなし）。高さは広場の地面から約+14〜+21で、ドームの内側。
- 空中補給：tick 3000 / 5400 / 7800 / 10200。ボーダー内のランダムな地表へ落下。投下の約15秒前（T-300tick）に予告（おおよその座標と種類）、投下時に正確な座標を通知し約180秒間光る。種類は3つ（抽選）：①バランス（上位チェスト表×2＋回復×1）②回復・食料（回復×3＋食料×1）③武器たっぷり（上位チェスト表×2＋通常チェスト表×1）。
- 今日のお題：試合開始時に全員共通で1つ抽選（チェスト8個／1キル／6分生存／素手で1キル／ジャンプ100回）。達成で回復アイテム1個、実績『お題達成』『お題マスター（累計5回）』。`/trigger oa.mission` で確認。
- 初心者サポート：試合開始時に回復アイテム1個を配布しヒントを表示（`#nobeginner br.flag`=1で無効。`/function oa:admin/beginner/off` `on`）。
- 終了時リザルト：優勝発表のあと、参加者ごとにキル・与ダメ・移動距離・チェスト開封数を表示。
- 実績（20種、試合をまたいで保持。管理者のみリセット可）：共通（初陣／ハットトリック／宝探し／最後の一人）、武器別（ぴちぴち『魚のまま20秒』＝敵の跳ねを20秒途切れさせない、キリング『25%の奇跡』＝攻撃を無効化、ゆうあ・lazi・ネロ・ゆったり・ほちきす・たやゆゆ・こまめ・ふろボール、各武器の初キル）。一覧は `/trigger oa.achv`、前回結果は `/trigger oa.result`。リセットは `/function oa:admin/ach/reset_all` と `reset_player {player:"名前"}`。

## 2. マップ
- 305x305、Y -20..0（広場上のドーム枠はY+29まで）。BRディメンション oa:br、中心地面 y=69。
- 生成：`tiles/place/N`（ブロック）、`tiles/water/N`（水）、`tiles/apply/N`（マーカー登録）、`delete/apply/N`（削除）。`/function oa:map/rebuild` で再生成。
- ジャンプ台27基。チェスト67個（うち上位チェスト：塔4・雪原の洞窟2・海中の遺跡2）。
- 雪原の洞窟2か所（北の雪原。部屋の中心 (27,-120) 入口は北（ゲート (27,-135)）／(-120,-129) 入口は西（ゲート (-135,-129)）。入口は幅3〜5のスロープで、丸太の門柱＋ランタンと、地表を走る長さ15のトウヒ板の参道が目印。室内にツララと青氷、上位チェスト1）。海中の遺跡2か所（南の海底 (-133,125) (131,113)、7x7の崩れたプリズマリン壁、角にシーランタン柱、上位チェスト1は水没）。いずれも地面より下か海中で、足場にならない。反映にはBR会場の再生成が必要。
- 帆船（南西の港、中心から (-78,111) 付近）：船首のバウスプリットと金の船首像、前マスト（赤白の帆・ペナント）、主マストの大旗・鎖・ランタン、船体の濃色ストライプと窓、デッキの樽と干し草、船尾屋根の手すり、船長室（地図台・書見台・赤いカーペット）。
- 遺跡の塔4基（南の草原）：7x7、石レンガ、屋根は地上+12（y=0）、入口は広場側、内部はしごで上階のチェストへ。座標は広場中心からの相対 (-138,58) (34,56) (-50,34) (14,66)。
### 中央広場ドーム
- 支柱8本（2x2、角度 18°+45°×j）、リング r=25/17/9、子午線8、風車状斜材、シーランタン節点56。枠ブロック1564、頂点Y+29。
- 設計制約：枠の最低足場は床+12（登り到達10.087超）。r≤8は空が開放。r≤23の約29%が枠下。
- 地面障害は支柱32セルのみ。

## 3. ロビー・練習場
- ロビートリガー：`oa.menu` `br.lobby` `oa.return` `br.join`。
- 練習場：待機中のみロビーのボタンから入場。インベントリは保存・消去、退出で復元。入口パネルで雨・昼夜・クールダウン操作。武器タグ1〜12。ダミーは装備別（なし/革/チェーン/金/鉄/ダイヤ）各2体、最新ダメージ表示。

- ロビーの装飾（1.9.102）：床の円形メダリオン、中央の噴水（水と柱）、四隅のオベリスク、外周の生け垣、ピラー間の梁（ペルゴラ）とつり下げランタン、噴水・花火のパーティクル。戦績・前回結果・実績の掲示は、地面から約1〜5ブロックの高さ。ロビー内の地図パネルは、洞窟・遺跡・塔・帆船・広場の位置入り（リソースパック1.9.34）。反映にはロビー更新（管理者の `oa.admin 14`）が必要。
- 練習場：すべてのアンデッド系モブ（ダミー含む）は日光で燃えない。
- チュートリアル：`/trigger oa.tutorial`（ロビーのメニューからも）。7ページ（目的・開始・探索・戦闘・縮小と補給・チーム・練習場）をクリックで進める。
- 戦績ボード（ロビー）：自分用の通算戦績（試合数・勝利・キル・実績数・順位）、前回の結果の壁、実績の壁。表示はオンラインのプレイヤーのみ。ロビー内で自動構築・更新（ロビーの再生成は不要）。
- 練習場の追加（レイアウト版 1997）：射程レーン（5〜40mの的）、高さ6m・10mの的、武器ごとの課題掲示、ダメージ計測 `/trigger oa.dps`（10秒間の与ダメージ）、模擬戦 `/trigger oa.spar`（ON同士で対戦、体力が少なくなるとKOで入口に戻り回復、本試合・他の練習者に影響しない）。模擬戦は近接と、対象選択を共有するスキルのみ対応。

## 4. 互換性
既存セーブ・管理コマンド互換。スコアボード版数は `oa:br/ui/version`。
