# 出撃ターミナルの配置・入口対応



## ロビー：出撃ターミナル（1.9.202）

登録原点の81×81範囲を再構築。帰還は(0.5,0,5.5)、南向き。受付はX=-10/0/10、Z=12、実クリック受付はZ=11。主通路X=-3～3、Z=0～10は頭上3ブロックを確保。左は武器展示と練習入口、右は既存計算を再利用する戦績・前回結果・実績のギャラリー、北側は浅い池・ベンチ・短いアスレチック、南外周は階段付きテラス。生成元scripts/gen_lobby_terminal.py。

一般入口 /oa は参加・観戦、チーム、TDM出撃武器、練習場、戦績・実績、遊び方。/oa maps・mode は一般には会場とルールの案内、ホスト・管理者は /oa host から全体設定・開始を操作する。BRは既存br.pickの10チーム、TDMはtdm.teamの赤青・未選択。変更は試合前かつ練習場の外だけ。TDM出撃武器は従来と同じ /tdm を開く。案内本は7ページ、最大1冊を空きスロットへ配布する。

管理入口 /oamenu は試合運営・プレイヤー・会場・ロビー／練習場・記録／実績・サーバー更新・診断／開発の7分類。旧ページと管理コードを残し、破壊的操作は確認画面へ。取得時の状態を表示する管理本は24ページで、既存生成入口scripts/gen_admin_book.pyを使用する。最新状態はメニューで確認。ホストは管理者の削除・再生成・更新権限を持たない。

反映は両パックをそろえて再起動後、登録管理者が試合停止中に /trigger oa.admin set 14。X/Z±40・Y−3～+44の手編集を上書きする。BR/TDM会場・練習場は再生成不要。旧ロビーは明示的な更新まで維持する。

| 入口 | 接続 | 権限 |
|---|---|---|
| 左受付 | /oa maps | 一般は案内、ホスト・管理者は会場選択 |
| 中央受付 | /oa mode | 一般はルール、ホストは設定への入口 |
| 右受付 | /oa team | 本人のチーム |
| 出撃台 | /oa host | ホスト・管理者 |
| 左展示室 | /oa practice | 本人の練習 |
| 右ギャラリー | /oa records | 本人の戦績・実績 |
| 本・旧公開メニュー | /oa | 全員 |
| 管理本・管理メニュー | /oamenu | 登録管理者 |

地図はリソースパック1.9.41のモデルを再利用。プレビューは生成ブロックの再構成であり、Minecraftクライアントの画面ではない。
