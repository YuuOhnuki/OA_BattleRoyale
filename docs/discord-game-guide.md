# Discord 用ゲームガイド（常設・貼り付け用）

## 投稿1：遊び方
**OAバトルロイヤルへようこそ！**
ロビーで参加ボタンを押して待機。ホストが開始パッドに立つとカウントダウンが始まります。
開始直後は短い保護時間があり、採掘用ツルハシだけ持って始まります。
マップを探索してチェスト・鉱石から装備を集め、最後まで生き残ろう！
はじめての方は `/trigger oa.tutorial` でチュートリアルが見られます。試合開始時には回復アイテムが1つ配られます。

## 投稿1b：マップ
試合のマップは管理者が選びます。**地上マップ**（草原・雪原・海・遺跡）と、新しい**ネザーマップ**（中央の宝物庫を、玄武岩・ソウルサンド・真紅・歪んだ森の4エリアが囲み、外側は溶岩の湖）があります。ネザーは水バケツが使え、ベッドは使えません。外周の柵の外は溶岩なので注意！

バージョンは、TABキーの一覧（名前の右）か、チャットに `/trigger oa.ver` で確認できます。

## 投稿2：ソロ／チーム
ソロでも、固定2〜3人のチームでも遊べます。チームはロビーで決めます。
エリアは時間とともに縮み、最後は中央広場に集まります。

## 投稿3：固有武器と練習場
友人モチーフの固有武器が登場！性能と演出が一つずつ違います。
本番前に、ロビーの「武器練習場」で全武器を試せます（待機中のみ）。
入るとインベントリは一時保管され、出ると元に戻ります。
練習場には、的（5〜40m・高所）、`/trigger oa.dps`（10秒ダメージ計測）、`/trigger oa.spar`（模擬戦：ON同士で対戦、KOで入口に戻ります）があります。

## 投稿4：試合中のイベントと実績
終盤になると中央のドームが点滅し、花火が上がります。決着の舞台は中央広場です。
試合中は数回、マップのどこかに「空中補給」が落ちます（バランス／回復・食料／武器たっぷりの3種）。約30秒前に予告が出て、空からパラシュートの箱が降りてきます。場所の名前と、あなたからの方角・距離が表示されます。場所はチャットで全員に通知されます。強いアイテムを取りに行くか、争いを避けるかは自分次第！
武器ごとの実績もあります。終盤の花火は演出だけでダメージはありません。条件を満たすと画面にトーストが出て、みんなに通知されます。
終わったら、キル数・与ダメ・移動距離・開けたチェスト数のリザルトと、最多キル・ダメージ王などの「ハイライト」が出ます。
脱落しても大丈夫！ 自動で生き残っている人の視点で観戦できます。`/trigger oa.spec` かチャットのボタンで、次の人・前の人・自由視点を切り替えられます。

## 投稿5：探索と実績
南の草原には「遺跡の塔」があります。入口は広場側、中のはしごを登ると、強いアイテムが入ったチェストがあります。
実績は全部で38種類。固有武器ごとの「3キル連続」マスター実績（10種）と、条件が非公開の隠し実績（6種）があります。試合をまたいで集められます。`/trigger oa.achv` で一覧、`/trigger oa.result` で前回の結果が見られます。

## 投稿6：今日のお題と洞窟・遺跡
試合ごとに「今日のお題」が1つ出ます（チェスト8個／1キル／6分生存／素手で1キル／ジャンプ100回）。達成すると回復アイテムがもらえます。`/trigger oa.mission` で確認できます。
北の雪原には「洞窟」（入口は黒っぽい丸太の門と板の参道が目印。ロビーの地図には載っていません）、南の海の底には「小さな遺跡」があり、どちらも強いアイテム入りのチェストが隠れています。
ロビーには戦績ボード・前回の結果の壁・実績の壁があります。
