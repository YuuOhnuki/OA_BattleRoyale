# Discord 用ゲームガイド（常設・貼り付け用）

## 投稿0：はじめに（リソースパック）
リソースパックは、サーバーに入ると自動で読み込まれます（確認が出たら「はい」）。ZIP を自分で入れる必要はありません。読み込まれないときは、サーバー一覧でこのサーバーを選んで「編集」→「サーバーリソースパック：有効」にしてから入り直してください。ZIP が欲しいときは、チャットで `/rp` と打つとダウンロードのリンクが出ます。

## 投稿1：遊び方
**OAバトルロイヤルへようこそ！**
ロビーで参加ボタンを押して待機。ホストが開始パッドに立つとカウントダウンが始まります。
開始直後は短い保護時間があり、採掘用ツルハシだけ持って始まります。
マップを探索してチェスト・鉱石から装備を集め、最後まで生き残ろう！
はじめての方は `/trigger oa.tutorial` でチュートリアルが見られます。試合開始時には回復アイテムが1つ配られます。

## 投稿1b：マップ
試合のマップは管理者が選びます。**地上マップ**（草原・雪原・海・遺跡）、**ネザーマップ**（中央の宝物庫を、玄武岩・ソウルサンド・真紅・歪んだ森の4エリアが囲み、外側は溶岩の湖）、新しい**洞窟マップ**があります。ネザーは水バケツが使え、ベッドは使えません。外周の柵の外は溶岩なので注意！

**洞窟マップ**は、岩の中に掘られたトンネルの迷路です。中央の地下神殿を、紫水晶の晶洞・繁茂した洞窟・鍾乳洞と地底湖・廃坑とディープダーク・古代都市の5つのエリアが囲みます。中は少し暗め。曲がり角の待ち伏せに注意！ 空中補給は天井から鎖で吊り下ろされ、隕石群の代わりに「落盤」（赤い円の場所に天井の岩が落ちる）が起こります。

ロビーの地図の足元にある「前のマップ」「次のマップ」の石のボタンを押すと、試合のマップを順に切り替えられます（地上→ネザー→洞窟→地上…。試合中は不可）。ボタンの上に、押すと切り替わる先のマップ名が出ています。
バージョンは、TABキーの一覧（名前の右）か、チャットに `/trigger oa.ver` で確認できます。

## 投稿1c：試合中の地図
試合が始まると「マップ」が配られます（ホットバーの右端）。手に持つと、自分の位置と向き（緑の矢印）、いまの安全地帯（赤い枠）、地点の名前が見られます。チーム戦では、生きている味方の位置も出ます。捨てたりチェストに入れたりはできず、倒されると消えます。

## 投稿2：ソロ／チーム
ソロでも、固定2〜3人のチームでも遊べます。チーム戦では、名前の表示は味方にだけ見えます。チームはロビーで決めます（試合が終わっても同じチームのまま。変えるときは別の色に乗り直す）。今回は参加しないときは、観戦パッドの隣の茶色の羊毛に乗るか、案内の本の「参加しない（ロビーで待つ）」で、ロビーや練習場で待てます。武器練習場は、試合中でも（試合に出ていなければ）入れます。地図の手前に色付きの羊毛が並んでいるので、入りたいチームの色に乗ってください（灰色は観戦）。
エリアは時間とともに縮み、最後は中央広場に集まります。エリアの外に出ても、2秒以内に戻ればダメージはありません。

## 投稿3：固有武器と練習場
友人モチーフの固有武器が登場！性能と演出が一つずつ違います。
キリングのマスクを着けている間は、いちばん近いプレイヤーが光って見えます（光って見えるのは着けている本人だけ）。
本番前に、ロビーの「武器練習場」で全武器を試せます（待機中のみ）。練習場にいる間も参加登録とチーム選択は保たれ、試合が始まると自動で荷物が戻ってロビーから試合へ出発します。
入るとインベントリは一時保管され、出ると元に戻ります。
練習場の武器の台座は、入口の鳥居をくぐってすぐの通路の両側にまとまっています。練習場には、的（5〜40m・高所）があります。入ると「練習場メニュー」の本が配られ、クリックだけでダメージ計測（10秒）、模擬戦（ON同士で対戦、KOで入口に戻ります）、昼・夜、晴れ・雨、クールタイムのリセット、持ち物を消す（本は配り直されます）を操作できます（`/trigger oa.dps` `/trigger oa.spar` も使えます）。

## 投稿3b：戦績
チャットで `/stats 名前` と打つと、その人の戦績（試合数・勝率・キル数・平均順位・最近の試合）が見られます。自分の名前でもOK。`/stats top` で勝利数ランキング、`/stats top kills` でキル数ランキング、後ろに `week` を付けると直近7日のランキングになります。

## 投稿4：試合中のイベントと実績
終盤になると中央のドームが点滅し、花火が上がります。決着の舞台は中央広場です。
試合中は数回、マップのどこかに「空中補給」が落ちます（3回。第1便 ★☆☆、第2便 ★★☆、第3便 ★★★ と、回を追うごとに中身が良くなります）。縮小と縮小の間に予告が出て、約30秒後に、縮んだあとのエリアの中の開けた地面へ、空からパラシュートの箱が降りてきます。場所の名前と、あなたからの方角・距離が表示されます（矢印は、見ている向きから見て補給物資のある方向を指します。上＝正面）。場所はチャットで全員に通知されます。強いアイテムを取りに行くか、争いを避けるかは自分次第！
武器ごとの実績もあります。終盤の花火は演出だけでダメージはありません。条件を満たすと画面にトーストが出て、みんなに通知されます。チャットの実績名や、拾った固有武器の名前にカーソルを合わせると、説明が見られます。
チェストを開けると、上に出る「開封済み」の札に、再補充までの残り時間（例：「再補充まで 3:12」）が出ます。開始6分で、中身が強くなって再補充されます。金色の光の粒が出ているチェストは「特別チェスト」で（各マップの中央に2つと、塔・洞窟・遺跡など）、強いアイテムや固有武器が出やすく、鉄の防具が必ず1つ入っています（再補充はありません）。
終わったら、キル数・与ダメ・移動距離・開けたチェスト数のリザルトと、最多キル・ダメージ王などの「ハイライト」が出ます。
脱落しても大丈夫！ 生き残っている人の視点で観戦できます（脱落直後は自由視点で、自動では追従しません）。`/trigger oa.spec` かチャットのボタンで、次の人・前の人・自由視点を切り替えられます。

## 投稿4b：災害と封印の宝珠
保護期間のあと、試合中は不定期に「災害」が起こります。画面の知らせ（雷の音とタイトル）が出てから5秒後に始まります（最後の3秒は「ポン、ポン、ポン」と音でカウントダウン）。対策を見て動こう。
・酸性雨（地上）：雨に当たると毎秒2ダメージ。屋根の下に入るか、頭に防具を着けると防げます。
・寒波（地上）：空の下は凍える。屋根の下か、革の胸当てで防げます。
・隕石群：赤い円が出たら、約3秒後に落ちます。円から離れるか、屋根の下に入れば当たりません（建物は壊れません）。
・毒霧：緑の霧の中は毎秒1ダメージと毒を受けます。
・地震：全員がふらつきます。発生の2秒後から、動く（歩く・走る・ジャンプ）と毎秒3ダメージ。止まって耐えよう。
・濃霧／灰嵐：視界が暗く狭くなります。
ネザーは天候系（酸性雨・寒波）が起こりません。
災害の警告は、画面下に3秒ごとに通常の表示と交互に出ます。
建物の中には「封印の宝珠」（海洋の心の形をしています）があります。右クリックして5秒そばにいると解錠でき、戦利品と回復がもらえます。解錠中は光の柱と鐘の音で場所が知られるので、周りに注意しましょう。

## 投稿5：探索と実績
南の草原には「遺跡の塔」があります。入口は広場側、中のはしごを登ると、強いアイテムが入ったチェストがあります。
実績は全部で68種類（うち隠し実績26種）。進捗画面（Lキー）のOAのタブに、「バトルロワイヤル」「マップ」「固有武器」の3つの枝が並び、枝分かれで順に解除していけます。固有武器ごとに、初キルやその武器ならではの実績があります（変な名前の実績も…？）。条件が非公開の隠し実績は、関連する枝の中に隠れていて、解除すると表示されます。練習場では実績は解除されません。試合をまたいで集められます。`/trigger oa.achv` で一覧、`/trigger oa.result` で前回の結果が見られます。

## 投稿6：今回のお題と洞窟・遺跡
試合ごとに「今回のお題」が1つ出ます（チェスト8個／1キル／6分生存／素手で1キル／ジャンプ100回）。達成するとごほうびがもらえます。`/trigger oa.mission` で確認できます。
北の雪原には「洞窟」（入口は黒っぽい丸太の門と板の参道が目印。ロビーの地図には載っていません）、南の海の底には「小さな遺跡」があり、どちらも強いアイテム入りのチェストが隠れています。
ロビーには戦績ボード（奥の黒い大きな板）・前回の結果の壁・実績の壁があります。
地上・ネザーのどちらのマップにも起伏があります。高い所は見晴らしが良く、くぼみは身を隠せます。
終盤はマップごとの派手な演出（ネザーは炎と灰）で盛り上がります。


### 1.9.194 武器調整
通常攻撃：ネロ・ゆったり5HP、こまめ4HP、いとりの紫の弾2HP。チェスト補充後（試合tick 7200以降）は、こまめ・ネロ・ゆったり・たやゆゆ・いとりの通常攻撃がさらに+1HP（順に5・6・6・6・3HP）。練習場では補充前の値。ゆったりのスキルは1HP、両者発光5秒、速度II／鈍足II各5秒、ランダムにどちらか一方へ暗闇3秒。


## チームデスマッチ（TDM、v1.9.195）

- バトロワとは別のゲームモード。2～10人、赤・青の2チーム。初期武器とチーム希望はロビーの「ゲームモード・TDM準備」ボタンまたは `/trigger oa.tdm set 10` のチャットメニューで選ぶ。モード変更はホスト・管理者だけが行え、`/trigger oa.game set 1` がBR、`set 2` がTDM。試合中は変更できない。
- 初期武器はぴちぴち・ネロ・ゆったり・ほちきす・こまめ・いとりの6種類。未選択はこまめ。いとりはTDM内だけ全6段階を最初から解放する。BR側のチーム選択（br.pick）は変更しない。TDMのチーム希望は独立して保存し、開始時に人数差を最大1人へ調整する（希望と異なる側になることがある）。
- 試合時間6000 tick（20TPSで5分）。敵プレイヤーを倒すたび1点。合計キル数の多いチームが勝ち、同点は引き分け。自滅・環境死は加点しない。バニラのキル帰属を使うため、敵が最後に攻撃した後の落下などはその敵の得点になり得る。チームの得点・残り秒を表示する。BRの縮小・災害・補給・勝利判定は走らず、BR戦績へは結果を書き込まない。
- チェーン一式・選んだ固有武器で開始。死亡後は3秒の観戦待機を経て自陣へ復活する。敵が12m以内にいない復活候補を優先して最大6回選び、見つからなければ安全な固定候補へ戻す。復活後2秒は相互攻撃保護（攻撃・被弾を止め、スキルも使えない）。何度でも復活できる。
- 地面の固有武器は4地点に30秒ごとに出現。近づくと現在の固有武器を交換する（1人1個）。交換はその生存中だけで、次の復活では開始前の選択武器に戻る。捨てた通常アイテムはアリーナ内で消す。
- 鉄防具強化は2地点に開始直後と30秒ごと、ダイヤ防具強化は中央に60秒ごとに出現（初回も60秒後）。近づくと一式を直接装着する。同じ強化・下位の強化では置換せず、次の人のために残す。強化は死亡で解除され、復活時はチェーン一式。
- 専用マップ `oa:tdm`「クロスドック倉庫」は81×65、左右対称の3レーンと迂回路・遮蔽物・小さな水路を持つ。床y64、通路y65～70、天井y71。遮蔽物は天井に接し、その上へ登って戦う足場を作らない。BR会場・練習場とは別ディメンション。初回開始時にチャンクを読み込んでから自動生成し、その後開始する。建築ソースは `scripts/gen_tdm_map.py`。
- ロビーの緑・ダイヤの開始パッドと従来の管理者開始コマンドは、TDM選択中はどちらもTDMを開始する。BRへ戻せば従来どおりソロ／チームの開始になる。開始前の荷物・ゲームモード・経験値は既存のBR保存／復元処理を共用し、終了・中止で戻す。TDM中の切断後は、同じ試合なら復活待ちから再参加、終了後なら預けた荷物を復元する。新規の途中参加は次の試合まで待つ。
- `/reload`・再起動時は進行中のTDMを中止して復元する。オフラインの荷物は次回ログインで復元する。観戦は既存の「観戦する」からTDMアリーナへ移動できる。

導入：データパック1.9.195 ＋ プラグイン0.15.0 ＋ リソースパック1.9.41。新ディメンションを追加するためサーバー再起動が必要。TDMアリーナとロビーの選択ボタンは自動追加。BR会場の再生成、`oa.admin 14`、練習場の更新は不要。

検証：静的検査・プラグインのビルド（既存単体テスト）・テスト用サーバーの起動チェックを実施。ユーザー指示により試合の自動テストは行わない。試合進行・復活・拾得・武器の挙動・マップの見た目／対戦バランスはゲーム内未確認。
