## 投稿0：はじめに（リソースパック）
リソースパックは、サーバーに入ると自動で読み込まれます（確認が出たら「はい」）。ZIP を自分で入れる必要はありません。読み込まれないときは、サーバー一覧でこのサーバーを選んで「編集」→「サーバーリソースパック：有効」にしてから入り直してください。ZIP が欲しいときは、チャットで `/rp` と打つとダウンロードのリンクが出ます。

## 投稿1：遊び方
**OAバトルロイヤルへようこそ！**
ロビーに入ると正面が「出撃ホール」。左がバトルロワイヤル受付、右がチームデスマッチ受付です。受付の端末を右クリックするか、チャットに /oa と打つと、参加・チーム・武器を準備できます。開始はホストが行います。
開始直後は短い保護時間があり、採掘用ツルハシだけ持って始まります。
マップを探索してチェスト・鉱石から装備を集め、最後まで生き残ろう！
はじめての方は `/trigger oa.tutorial` でチュートリアルが見られます。試合開始時には回復アイテムが1つ配られます。

## 投稿1b：マップ
試合のマップは管理者が選びます。**地上マップ**（草原・雪原・海・遺跡）、**ネザーマップ**（中央の宝物庫を、玄武岩・ソウルサンド・真紅・歪んだ森の4エリアが囲み、外側は溶岩の湖）、新しい**洞窟マップ**があります。ネザーは水バケツが使え、ベッドは使えません。外周の柵の外は溶岩なので注意！

**洞窟マップ**は、岩の中に掘られたトンネルの迷路です。中央の地下神殿を、紫水晶の晶洞・繁茂した洞窟・鍾乳洞と地底湖・廃坑とディープダーク・古代都市の5つのエリアが囲みます。中は少し暗め。曲がり角の待ち伏せに注意！ 空中補給は天井から鎖で吊り下ろされ、隕石群の代わりに「落盤」（赤い円の場所に天井の岩が落ちる）が起こります。

**天空島マップ**は、空に浮かぶ大きな城の島「天空城」と、そのまわりの島々の戦場です。まわりの島は**再生成ごとに17種類から3〜6個、場所も種類も変わります**。砂漠・雪・町・飛行船などに加え、森林・巨木・風車・キノコ・採掘・段丘・砦の島があります。各島はガラスの半球に包まれ、城からの橋の先に入口があります。中央の水場には四方の出口を用意しました。落下時はY=0で突風に打ち上げられ、着地まで落下ダメージなし。着地前に再び落ちた場合は再使用できず、Y=-10以下なら奈落死します。地面に着くとまた使えます。エンドにも同じ救済と、32か所ずつの小さな足場・上昇気流があります。

**エンドマップ**は、エンドストーンの段々の丘とコーラスの林、そびえ立つ黒曜石の柱の浮遊島です。中央の「竜の祭壇」は岩盤の構造物で、頂点にドラゴンの卵。真紅と紫の高い塔が密集した「エンドの塔街」もあります。エンドポータルで離れた島へワープでき、重力異常エリアでは体が軽くなります。エンドの島の配置は毎回同じです。エンドの試合では、**防御力+6のエリトラ**を着た状態で始まります（外すこともできます）。重力異常の島では、島全体で体が軽くなります。

天空島とエンドは、**再生成時にまわりの島の中身を抽選します**。天空島は選択時に「再生成する」「既存マップを使用」を確認します。エンドは橋と土台を残し、16種類から各外島の候補を選びます。試合のたびに勝手に作り直す設定は既定で無効です。

バトルロワイヤル受付の「地上」「ネザー」「地下（古代都市）」「天空島」「エンド」の5つの台で、ホストがマップを選びます。ほかの人が押すと、その会場の説明が出ます。奥の大きなパネルに、いま選ばれているマップが表示されます。
受付の大きなパネルの下にある5つのボタン（地上・ネザー・洞窟・天空島・エンド）でも、ホストがマップを切り替えられます。ボタンの上に「選択中」「未生成」が出ます。
バージョンは、TABキーの一覧（名前の右）か、チャットに `/trigger oa.ver` で確認できます。

## 投稿2：ソロ／チーム
ソロでも最大3人のチームでも遊べます。チームはバトルロワイヤル受付の「チーム」端末か /oa で選択し、試合後も希望を保持します。不参加で待つ・観戦する場合は /oa play から選んでください。広場の右手の武器展示室の奥から練習場に入れます。試合中でも、試合に出ていない人は練習できます。
安全地帯（安置）は**赤と黄色の縞模様の粒の壁で囲まれた円**です。マップの中心に向かって、時間とともに5回縮みます（最後は半径10）。壁の足元には明るい線が、次の安置の境目には白い点線が地面に出ます。壁は通り抜けられますが、外にいると毎秒ダメージを受けます（収縮ごとに ♡×0.5 → 1 → 1.5 → 2 → 3 と大きくなる）。外に出ても2秒以内に戻ればダメージはありません。収縮の30秒前・10秒前・開始・完了はチャットで知らせ、安置の外にいる間は画面の縁が赤くなり、画面下に「⚠ 安全地帯の外です！」と出ます。試合中の地図には、今の安置（赤）と次の安置（白）が描かれます。

・酸性雨（地上）★★★★☆：雨に当たると毎秒2ダメージ。屋根の下に入るか、頭に防具を着けると防げます。

・毒霧 ★★★★☆：中心から緑の霧が広がり、中は毎秒1ダメージと毒を受けます。

### 1.9.194 武器調整
通常攻撃はネロノワール・ゆったり5HP、こまめ4HP、昭心の紫弾2HP。補充後の既存+1HPは維持。ゆったり・ネロ・たやゆゆの通常効果は20%。ゆったりのスキルはノックバック7相当（水平3.5・上0.4）、通常の当選は水平の強さが半分（水平1.75・上0.4）。スキルのダメージ・CTは変更しない。

# 管理者向け：手編集マップとホログラム

手編集したロビー・会場は `/oaplugin map save lobby`（会場は `br` / `nether` / `cave` / `tdm`）で保存できます。完了後は通常の再生成でも保存版を使用します。先に `/oaplugin map info lobby` で保存範囲を確認してください。

文字表示は `/oaplugin holo create welcome <aqua>ようこそ` で作成し、`text`・`move`・`set`で編集できます。既存表示は `adopt` で登録できます。編集後、マップをもう一度保存すると再生成にも残ります。範囲・復元・履歴・設定の詳しい操作は [マップ編集ガイド](map-editor.md) を参照してください（プラグイン0.35.0以降）。

**✚ 初心者救済モード**（ホストがオンにしたときだけ）
・チェスト補充（試合開始から6分）より前に倒れても、補充のときに復活します
・復活すると、固有武器1つ（ゆうあ以外）・チェーンの防具一式・採掘用ツルハシ・パン5個・包帯5個を持っています（武器は足元）
・降参・切断したとき、チームが全滅したときは復活しません
