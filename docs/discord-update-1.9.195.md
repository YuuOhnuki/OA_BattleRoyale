# v1.9.195 チームデスマッチ追加

5分間の赤vs青チーム戦です。倒されても3秒後に復活し、チームの合計キル数で勝負！

- ロビーのオレンジの「ゲームモード・TDM準備」ボタンで、初期武器とチーム希望を選択。ホストがTDMへ切り替えて開始パッドに乗ると開始します。
- ぴちぴち・ネロ・ゆったり・ほちきす・こまめ・いとりから選択し、チェーン一式でスタート。いとりは全スキル解放済み。
- 小さな専用倉庫マップで、遮蔽物と迂回路を使って戦います。味方同士のダメージはなく、復活後2秒は相互攻撃保護。
- 地面の武器を拾うとその生存中の武器を交換。鉄・ダイヤの防具強化を拾うと一式がアップグレードします。死亡後は初期武器とチェーンに戻ります。
- 中央のダイヤ防具は1分ごと。試合は必ず5分で終了し、同点なら引き分けです。

導入：データパック1.9.195＋プラグイン0.15.0＋リソースパック1.9.41。サーバー再起動が必要。会場再生成・ロビー全体・練習場の更新は不要です。
検証：静的検査・ビルド・起動チェック。試合テストはユーザー指示で省略し、対戦動作と見た目は未確認です。
