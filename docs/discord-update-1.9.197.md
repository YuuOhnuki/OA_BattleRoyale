# v1.9.197 TDMの表示・回復・武器交換・演出

- チーム得点・保有武器名・CT・残り時間を常時表示。ロケーターバーは無効。
- 即時4HP回復のドロップを時々出現。キル時は再生II・速度上昇IIを5秒、満腹度をゲージ2つ分回復（矢5本も継続）。
- 地面のドロップに名前と操作を表示。固有武器はシフトを押して交換し、元の武器をその場に残します。武器の消耗・エンチャントなどは保持。
- マップに明るい照明・目印・両端から登れる整備通路を追加。151か所の候補地点と経路を静的検査。
- キル・拾得・回復・復活・開始・勝敗などへ音と粒子を追加。

対応：データパック1.9.197＋プラグイン0.17.0＋リソースパック1.9.41。両方をそろえて再起動。次回TDM開始時に会場を自動再生成（TDM会場の手編集は上書き）。BR会場・ロビー全体・練習場の更新は不要。

検証：静的検査・候補地点と経路の静的検査・ビルド・起動チェック。試合の自動テストはユーザー指示で省略。人の操作・見た目・音のゲーム内確認は未実施。
