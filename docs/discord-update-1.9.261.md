# v1.9.261

**🎯 お題が24種類に**
・「弓かクロスボウで1キル」「残り3人まで生き残る」など12種類を追加

**👻 脱落しても遊べる**
・脱落すると、次の補給が落ちる方角と次の災害に投票できます
・ホストがONにしていれば、脱落した人どうしで1v1ができます（初心者救済モードのときはなし）

**★ 特別ルール**
・低重力・俊足・体力2倍・災害2倍など、ホストが試合ごとに選べます

**🔥 信号弾**
・チェストからまれに出ます。使うと少しあとに足もとへ補給が届きます（みんなに知られます）

**🏅 熟練度と見た目**
・武器を使うほど熟練度が上がり、称号がもらえます（チャットの名前の前に出ます）
・キルや優勝の回数で、キルの演出・ロビーの足あと・優勝の演出が解放されます
・`/stats weapon` で武器ごとの勝率が見られます
