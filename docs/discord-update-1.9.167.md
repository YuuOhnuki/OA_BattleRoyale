# 1.9.167 アップデート告知（Discord用）
**OAバトルロイヤル v1.9.167　新マップ「洞窟」**
・新しいマップ「洞窟」を追加しました！ 岩の中に掘られたトンネルの迷路で、中央の地下神殿を5つのエリアが囲みます。
　紫水晶の晶洞／繁茂した洞窟／鍾乳洞と地底湖／廃坑とディープダーク／古代都市の町並み
・中は暗めです。曲がり角の待ち伏せに注意！
・洞窟では、空中補給は天井から鎖で吊り下ろされます。隕石群の代わりに「落盤」が起こります（赤い円から離れよう）。
・ロビーの地図の足元に「洞窟」ボタンが増えました。
・実績「地底の戦場へ」「地底の覇者」を追加。「全マップ制覇」は3つのマップすべてで優勝が条件になりました。
