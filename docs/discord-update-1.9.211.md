# v1.9.211

**キルログ**
- 倒されたときのメッセージを「〇〇 は △△ の［武器名］で倒された」に統一しました。固有武器はその武器の名前、通常の武器は持っていた武器の名前が出ます。
- 「魔法で殺された」などの分かりにくい表示はなくなりました。エリア外・災害・落下などで倒れたときは「△△ との戦闘中に 酸性雨 で倒れた」のように出ます。

**アイテム**
- チェスト・補給物資のふろボールが、拾ったあとに中身が書き換わって手持ちの物と重ならなかった問題を直しました。
- 包帯の回復量を ♥×3 に増やしました（手持ちの包帯も自動で新しい物になります）。

**武器の調整**
- ほちきす：拘束の範囲を半径約4mに広げました。
- いとり：
  - 解放の進行度は、鉱石4個（チェストは2個のまま）で＋1になりました。
  - ガイア：ダメージを ♥×1.5 に。
  - ヴァレサ：約6m跳び上がり、8m以内の一番近い敵へ落下します。
  - シロネン：強化中は、フリンズの雷の追撃も1.5倍になります。
  - フリンズ：効果時間10秒、雷の追撃に鈍足II（2秒）と発光（3秒）を追加。雷の演出を派手にしました。

**練習場**
- 入口の鳥居の先を「武器庫」に作り直しました。左が固有武器、右が通常武器と防具のマネキンです。
- 展示を右クリックすると、武器がそのまま持ち物に入ります（固有武器は持っている物と入れ替え）。マネキンをクリックすると防具一式に着替えます。クリックした展示は少し光ります。
