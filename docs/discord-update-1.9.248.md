# v1.9.248

**🏹 弓・クロスボウのロックオン**
弓かクロスボウを持ってしゃがみ、30m以内の相手に照準を約1秒合わせるとロックオンします
・ロックした相手は自分にだけ光って見えます
・しゃがんだまま撃つと、遅い矢が相手へ曲がって飛びます（ダメージは通常の75%）
・撃ったあと1秒は弓・クロスボウが使えません
・ロックオンされると音が鳴ります。物陰に隠れれば外れます

**🗡 武器の調整**
・刀：ダメージを1下げて、範囲を広くしました。見た目も刀になりました
・らじの音波：上下にも届くようになりました（縦に4ブロック広い円柱）
・追尾弓・ロックオン槍・木のバットはなくなりました
