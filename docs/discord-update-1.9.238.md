# v1.9.238 更新

- ゆったりのスキルのノックバックを7相当（水平3.5・上0.4）へ変更。通常攻撃は25%の確率でその半分の水平の強さ（水平1.75・上0.4）。
- 天空島のy=0で約150ブロック打ち上げる突風を異界（エンド）にも適用。着地すると再使用でき、着地まで落下ダメージなし。
- 天空島・異界の小さい救済足場を各4→32か所（8倍）。従来の4か所を残し、追加分にも上昇気流を設置。追加の足場に物資は置かない。

- 自動検査で見つかった地上・ネザーの途中参加配置も修正。spreadplayersの成功後に床・頭上を検査し、柵・塀・ゲートなど不適切な床なら最大30回選び直す。安全な位置がなければ所持品を保存する前に中止する。

対応：データパック1.9.238＋プラグイン0.49.2＋リソースパック1.9.47（変更なし）。

反映：両方そろえて `/oaplugin update apply` で再起動後、`/function oa:map/rebuild_sky` と `/function oa:map/rebuild_end` を順に実行。会場の手編集は上書きされる。ロビー更新・練習場更新は不要。
