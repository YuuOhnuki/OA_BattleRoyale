# v1.9.200 更新

- TDM終了タイトルを3秒保持し、赤青の最終スコアも表示。
- 復活待機中のプレイヤーをスキルの標的から除外。ゆったりの待機中発動・帰還を停止し、死亡時に帰還予約を破棄。
- TDMメニューを2段の固有モデルアイコンへ整理。一般プレイヤーは武器選択のみ、ホスト・管理者は試合前にモード切替・開始も操作可能。
- 開始前10秒にも選択画面を自動で開き、選び直した武器を開始時に配布。
- インベントリ内のゆー発動時も、通常トーテムではなくゆーのモデルで演出。
- BRの非優勝者には自身の順位、サブタイトルには優勝者名を表示。同時脱落は同順位、チーム戦も保存する個人順位と同じ基準。

対応：データパック1.9.200＋プラグイン0.20.0＋リソースパック1.9.41。両方配置後に再起動。会場・ロビー・練習場の更新は不要。

検証：静的検査・ビルド・起動確認。試合の自動テストはユーザー指示で省略。メニュー操作・モデル演出・戦闘・順位表示の実操作は未確認。
