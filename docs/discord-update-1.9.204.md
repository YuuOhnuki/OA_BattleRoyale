# v1.9.204 説明表記の統一

- 武器の呼称を指定の日本語名・英語IDへ統一。旧関数ID・保存データ・モデルIDは互換のため保持し、neronoir/hochikisu/yu/froschの入手関数を追加。
- アイテム・練習場の詳細チャット・展示・武器選択／管理メニューを共通カタログから生成。「モチーフ／通常攻撃／右クリック／CT」の順と灰色の項目名・白色の値へ統一。
- 体力はハート1個＝2HP、満腹度は食料アイコン1ゲージ＝内部2ポイントとして併記。専用の小さなアイコンをリソースパック1.9.42へ追加。
- ゆー・ふろっしゅ・回復／食品などは固有武器と同時所持できる旨を明記。いとりも同じ基本書式にし、詳細側だけに各スキルを列挙。
- 古いダメージ・効果時間・自動発動・ガチャ結果の説明を実装に合わせて更新。通常説明は初期値だけ。実際に強化された武器のアイテム説明だけに増加後の値と＋1HPを表示。
- /oaweapon <英語ID> で同じ詳細説明を参照できる。案内本に単位の説明と入口を追加。全12種の短文・効果・改善案はWEAPONS_JA.mdとdocs/weapon-description-review.mdへ整理。性能の改善案は未適用。

対応：データパック1.9.204＋プラグイン0.23.0＋リソースパック1.9.42。3つをそろえて再起動。ロビー建築の再建・BR/TDM会場・練習場の再生成は不要。ロビーの表示名は試合停止中に管理者が /trigger oa.admin set 46 で更新。練習場の既存名札は起動時に更新。既存所持品の説明も順次更新する。

検証：静的・ビルド・起動・アイテム説明の適用確認。試合の自動テストは指示で省略。クライアントでのアイコン描画・本・ホバーの見え方は未確認。
