# 1.9.180 アップデート告知（Discord用）
**OAバトルロイヤル v1.9.180**
・**試合中の地図**：試合が始まると「マップ」が配られます。手に持つと、自分の位置と向き（緑の矢印）、安全地帯（赤い枠）、地点の名前、チーム戦では味方の位置が見られます。
・ロビーの地上マップに、市街地・雪山・森林・小島・湖の名前を追加しました。
・実績「明日早いので寝ます」「そろそろ寝るか...。」は、帽子（マスク）を被っている間に一度もキルできなかったら解除されるようになりました（試合全体のキル数は関係なし）。
・リソースパックはサーバーに入ると自動で読み込まれます。ZIP のリンクが欲しいときは `/rp` と打ってください。
・管理者が試合の途中で参加させた人が、地面に埋まったり、試合後に持ち物を戻せなかったりする不具合を直しました。
※データパック1.9.180＋リソースパック1.9.40＋プラグイン0.5.0。
